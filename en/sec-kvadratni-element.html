Chapter 7 Basics of FEM for bars and trusses

7.4 The quadratic element and Gauss integration (kvadratni element in Gaussovo integriranje)

The linear element gives a constant axial force on each element. When the load along the bar varies, the true axial force varies too, and a stepped approximation follows it only as the number of elements grows. What do we gain if on each element we take a parabola instead of a line, and how do we compute the integrals that the parabola brings when they are no longer simple? First we write the element with three nodes, its matrix and its forces. Then we look for a way in which a computer evaluates integrals that we cannot write in closed form, and we show what happens if this way is chosen too sparingly. At the end we measure how fast the approximation improves as the elements are made smaller. We stay with the bar of chapter 6, with one displacement per node.

7.4.1 The element with three nodes (element s tremi vozlišči)

The quadratic element (kvadratni element) is a finite element (definition 7.1) with nodes at both ends and in the middle, at \(x = 0\), \(h/2\) and \(h\), where \(h\) is the length of the element. The column \(\vek d_{\mathrm{e}} = (d_1, d_2, d_3)\) holds the displacements of these three nodes. The field on the element is a quadratic polynomial that takes these values at the nodes. We write it with the shape functions (definition 7.2), which are now quadratic polynomials, equal to \(1\) at their own node and to zero at the other two. The function \(\psi_2\) must have zeros at \(x = 0\) and \(x = h\), so \(\psi_2 = c\,x\,(x - h)\), and the condition \(\psi_2(h/2) = 1\) gives \(c\,(h/2)(-h/2) = 1\), so \(c = -4/h^2\). In the same way \(\psi_1\) has zeros at \(h/2\) and \(h\), so \(\psi_1 = c\,(x - h/2)(x - h)\) with \(c\,(-h/2)(-h) = 1\), so \(c = 2/h^2\), and \(\psi_3\) has zeros at \(0\) and \(h/2\), so \(\psi_3 = c\,x\,(x - h/2)\) with \(c\,h\,(h/2) = 1\), so again \(c = 2/h^2\). The results are

\[\begin{aligned} \psi_1 &= \frac{2\,(x - h/2)(x - h)}{h^2} , \qquad \psi_2 = -\frac{4\,x\,(x - h)}{h^2} , \\ \psi_3 &= \frac{2\,x\,(x - h/2)}{h^2} , \end{aligned} \tag{7.24}\]

drawn in figure 7.10. The field on the element is \(u_{\mathrm{h}} = \psi_1 d_1 + \psi_2 d_2 + \psi_3 d_3\), and at a node it equals the displacement of that node. The same polynomials are written in ONATE1 (3.11), PDF p. 103, with the coordinate \(\xi = 2x/h - 1\), and in EP (8.2.18), p. 535, with the nodes \(x_1, x_2, x_3\).

The sum of the shape functions is \(1\) here too. In the computation, \(2x^2 - 3hx + h^2\) remains for \(\psi_1 h^2\), \(-4x^2 + 4hx\) for \(\psi_2 h^2\) and \(2x^2 - hx\) for \(\psi_3 h^2\), and their sum is \(h^2\). If all three nodes have the same displacement \(c\), then \(u_{\mathrm{h}} = c\) on the whole element: a rigid shift of the element gives no deformation, as for the linear element (lemma 7.3).

What changes? The derivatives \(\psi_{\mathrm{i}}'\) are no longer constant but linear, so the strain \(u_{\mathrm{h}}'\) and the axial force \(N_{\mathrm{h}} = EA\,u_{\mathrm{h}}'\) are linear functions on the element. How this affects the computation is shown by the hanging bar (section 7.2.3). Before we try it, we compute the matrix and the forces of the element.

Lemma 7.23 Stiffness matrix and forces of the quadratic element (togostna matrika in sile kvadratnega elementa)

Let a quadratic element of length \(h\) have axial stiffness \(EA\), constant on the element, and let the load \(q\) along the axis be constant. Then its stiffness matrix \(\mat k_{\mathrm{e}}\) (definition 7.4) and the vector of consistent nodal forces \(\vek f_{\mathrm{e}}\) (definition 7.7) are

\[\mat k_{\mathrm{e}} = \frac{EA}{3h} \begin{pmatrix} 7 & -8 & 1 \\ -8 & 16 & -8 \\ 1 & -8 & 7 \end{pmatrix} , \qquad \vek f_{\mathrm{e}} = \frac{q\,h}{6} \begin{pmatrix} 1 \\ 4 \\ 1 \end{pmatrix} . \tag{7.25}\]

For a column \(\vek d_{\mathrm{e}}\) we have \(\vek d_{\mathrm{e}}^{\mathsf T}\mat k_{\mathrm{e}}\vek d_{\mathrm{e}} = 0\) exactly when \(\vek d_{\mathrm{e}} = c\,(1, 1, 1)\), and then \(\mat k_{\mathrm{e}} \vek d_{\mathrm{e}} = \vek 0\).

Proof

We must show four things: the values of the entries of \(\mat k_{\mathrm{e}}\), the values of the entries of \(\vek f_{\mathrm{e}}\), the zero column, and that there is no other zero column.

  1. Differentiating equation (7.24) gives \(\psi_1' = (4x - 3h)/h^2\), \(\psi_2' = (4h - 8x)/h^2\), \(\psi_3' = (4x - h)/h^2\). The sum is \(0\), because the sum of the shape functions is constant.
  2. The entry \(k_{\mathrm{ij}} = \int_0^h EA\,\psi_{\mathrm{i}}'\,\psi_{\mathrm{j}}'\,\mathrm{d}x\) is an integral of a polynomial of degree 2 (lemma 7.5, which writes the same matrix for the linear element). By lemma 3.39 and the fundamental theorem of calculus (theorem 3.40), \(k_{11} = \frac{EA}{h^4}\int_0^h (16x^2 - 24hx + 9h^2)\,\mathrm{d}x = \frac{EA}{h}\,(\tfrac{16}{3} - 12 + 9) = \frac{7\,EA}{3h}\).
  3. In the same way \(k_{12} = \frac{EA}{h^4}\int_0^h (-32x^2 + 40hx - 12h^2)\,\mathrm{d}x = \frac{EA}{h}\,(-\tfrac{32}{3} + 20 - 12) = -\frac{8\,EA}{3h}\), \(k_{13} = \frac{EA}{h^4}\int_0^h (16x^2 - 16hx + 3h^2)\,\mathrm{d}x = \frac{EA}{h}\,(\tfrac{16}{3} - 8 + 3) = \frac{EA}{3h}\) and \(k_{22} = \frac{EA}{h^4}\int_0^h (64x^2 - 64hx + 16h^2)\,\mathrm{d}x = \frac{EA}{h}\,(\tfrac{64}{3} - 32 + 16) = \frac{16\,EA}{3h}\).
  4. The sum of row \(i\) is \(\sum_{\mathrm{j}} k_{\mathrm{ij}} = \int_0^h EA\,\psi_{\mathrm{i}}' \sum_{\mathrm{j}} \psi_{\mathrm{j}}'\,\mathrm{d}x = 0\) by step 1. Therefore \(k_{23} = -k_{21} - k_{22} = -8EA/(3h)\) and \(k_{33} = -k_{31} - k_{32} = 7EA/(3h)\), where \(k_{31} = k_{13}\) and \(k_{32} = k_{23}\) because \(\mat k_{\mathrm{e}}\) is symmetric. This gives all entries of the matrix, and \(\mat k_{\mathrm{e}} (1, 1, 1)^{\mathsf T} = \vek 0\).
  5. The force is \(f_{\mathrm{i}} = \int_0^h q\,\psi_{\mathrm{i}}\,\mathrm{d}x\). For \(\psi_2\) we have \(\int_0^h \psi_2\,\mathrm{d}x = -\frac{4}{h^2}\,(\tfrac{h^3}{3} - \tfrac{h^3}{2}) = \tfrac{2h}{3}\). Since \(\psi_3(x) = \psi_1(h - x)\), \(\psi_1\) and \(\psi_3\) have the same integral, and since the sum of the integrals of all three is \(\int_0^h 1\,\mathrm{d}x = h\), each of them is \(h/6\). So \(\vek f_{\mathrm{e}} = q\,(h/6, 2h/3, h/6)\).
  6. Let \(\vek d_{\mathrm{e}}^{\mathsf T}\mat k_{\mathrm{e}}\vek d_{\mathrm{e}} = EA \int_0^h (u_{\mathrm{h}}')^2\,\mathrm{d}x = 0\). The derivative \(u_{\mathrm{h}}' = a + b\,x\) is linear, and the integral of its square is \(\int_0^h (a + bx)^2\,\mathrm{d}x = h\,\big((a + bh/2)^2 + b^2h^2/12\big)\). This sum of two squares is zero only for \(b = 0\) and \(a = 0\), so \(u_{\mathrm{h}}\) is constant on the element and all three nodal displacements are equal. Conversely, by step 4, \(\mat k_{\mathrm{e}}\,c\,(1, 1, 1)^{\mathsf T} = \vek 0\).

Source: ONATE1 (3.36) and (3.37), PDF p. 111, which writes the matrix as \(\frac{EA}{6l}\) times the matrix with entries \(14, -16, 2, 32\), so the same matrix, and EP (8.2.32), p. 539, in the form \(\frac{EA}{3h}\) times the matrix with entries \(7, -8, 1, 16\) and \(\frac{qh}{6}\,(1, 4, 1)\). The proof in steps is ours.

The eigenvalues of the matrix \(\mat k_{\mathrm{e}}/(EA/h)\) are \(0\), \(2\) and \(8\) (SymPy). The zero belongs to the rigid shift, and the lemma says that this is the only direction without energy. We test it on the hanging bar of section 7.2.3. Its length is \(L = 10\) m, its axial stiffness \(EA = 1{,}5394 \cdot 10^7\) N, its self weight \(q = 6{,}0097\) N/m, the upper end is fixed and the lower end is free. Take a single quadratic element, \(h = L\). By equation (7.25) the forces of the element are \((10{,}016, 40{,}065, 10{,}016)\) N, and their sum is \(q L = 60{,}097\) N. The upper node is fixed, so we strike out the first row and column. The system that remains is

\[\frac{EA}{3h} \begin{pmatrix} 16 & -8 \\ -8 & 7 \end{pmatrix} \begin{pmatrix} d_2 \\ d_3 \end{pmatrix} = \begin{pmatrix} 40{,}065 \\ 10{,}016 \end{pmatrix}\ \text{N} , \tag{7.26}\]

with \(EA/(3h) = 5{,}1313 \cdot 10^5\) N/m. The solution is \(d_2 = 14{,}640\) µm and \(d_3 = 19{,}520\) µm, and these are the exact displacements of the middle and the end of the hanging bar (section 6.4.2). For this load the true displacement is the quadratic polynomial \(a\,(2Lx - x^2)\), which lies in the field of the quadratic element, so the element gives the true field everywhere, not only at the nodes (the same is shown by ONATE1, example 3.4, PDF p. 123). The axial force \(N_{\mathrm{h}} = EA\,u_{\mathrm{h}}'\) is linear and equal to the true one, \(N = q\,(L - x)\): \(60{,}10\) N at \(x = 0\), \(45{,}07\) N at \(2{,}5\) m, \(30{,}05\) N at \(5\) m, \(15{,}02\) N at \(7{,}5\) m and zero at \(x = L\) (SymPy). The linear element with two elements gave \(45{,}07\) N and \(15{,}02\) N, with four elements \(52{,}59\) N at the support. The reaction from the first row, \(r = (EA/3h)(-8 d_2 + d_3) - q h/6\), is \(-60{,}097\) N, equal to the weight of the bar.

Why is the middle force \(4qh/6\), but \(q h/6\) at the ends? A naive division would assign to each node the load of the part of the element nearest to it, so \(\tfrac14\), \(\tfrac12\), \(\tfrac14\) of the weight \(q h\). The consistent forces are the work of the load on the field of the element, \(f_{\mathrm{i}} = \int q\,\psi_{\mathrm{i}}\,\mathrm{d}x\), so the areas under the shape functions multiplied by \(q\). The area under \(\psi_2\) is \(2h/3\), under \(\psi_1\) and \(\psi_3\) only \(h/6\) each, because \(\psi_1\) and \(\psi_3\) have negative parts that reduce the area (figure 7.11). The middle node therefore carries four times as much load as an end node (ONATE1, PDF p. 111, which calls this a result that is not the obvious one and a consequence of the principle of virtual work and the quadratic approximation). Together the areas give \(h\), so the sum of the forces is equal to the weight \(q h\).

What if we do not load the middle node? Then the second equation of the element is \(\tfrac{EA}{3h}\,(-8d_1 + 16d_2 - 8d_3) = 0\), so \(d_2 = (d_1 + d_3)/2\). If we eliminate the middle displacement (the same elimination step as in section 6.3.4, except that the pivot is the middle entry \(16\) instead of the first), what remains is

\[\begin{aligned} &\frac{EA}{3h}\left( \begin{pmatrix} 7 & 1 \\ 1 & 7 \end{pmatrix} - \frac{1}{16} \begin{pmatrix} -8 \\ -8 \end{pmatrix} \begin{pmatrix} -8 & -8 \end{pmatrix} \right) \\ &\quad = \frac{EA}{3h} \begin{pmatrix} 3 & -3 \\ -3 & 3 \end{pmatrix} = \frac{EA}{h} \begin{pmatrix} 1 & -1 \\ -1 & 1 \end{pmatrix} , \end{aligned} \tag{7.27}\]

the matrix of the linear element. Without a load along the element the third node therefore adds nothing, because the true solution is then linear (\(EA\,u'' = 0\)) and the middle displacement is the mean of the two end ones, which a line already has. The third node pays off only under a load along the element.

7.4.2 Mathematics: Gauss integration (Gaussovo integriranje)

For a quadratic element with constant stiffness the integrals are polynomials of degree two, which we know how to compute. When the stiffness or the load varies along the element by a complicated law, or when the middle node is not in the middle of the element, the integrands contain rational functions and the integral is no longer simple (ONATE1, PDF p. 111). A computer program does not compute a primitive function but replaces each element integral by a sum of values of the integrand at a few points. How do we choose the points and the weights so that the sum equals the integral for as many integrands as possible?

First the unit interval. The element \([x_{\mathrm{a}}, x_{\mathrm{b}}]\) with midpoint \(x_{\mathrm{m}} = (x_{\mathrm{a}} + x_{\mathrm{b}})/2\) and length \(h\) is mapped to \([-1, 1]\) by \(x = x_{\mathrm{m}} + \xi\,h/2\). Let \(g\) be a continuous function on the element, extended to the left of \(x_{\mathrm{a}}\) by the constant value \(g(x_{\mathrm{a}})\) and to the right of \(x_{\mathrm{b}}\) by the constant value \(g(x_{\mathrm{b}})\), so that it is continuous on an open interval containing the element, and \(G\) its primitive function, which exists by theorem 3.40, item 2. By the chain rule (lemma 4.43, the special case of a function \(G\) that does not depend on the other coordinates, along a curve on the \(x\) axis, with \(G\) continuously differentiable because \(G' = g\) is continuous), \(\frac{\mathrm{d}}{\mathrm{d}\xi}\,G(x_{\mathrm{m}} + \xi h/2) = g(x_{\mathrm{m}} + \xi h/2)\,\tfrac h2\), so by item 1 of the same theorem

\[\int_{\mathrm{x}_\mathrm{a}}^{x_{\mathrm{b}}} g\,\mathrm{d}x = G(x_{\mathrm{b}}) - G(x_{\mathrm{a}}) = \frac h2 \int_{-1}^{1} g\big(x_{\mathrm{m}} + \xi\,\tfrac h2\big)\,\mathrm{d}\xi . \tag{7.28}\]

The factor \(h/2\) is the ratio of lengths \(\mathrm{d}x/\mathrm{d}\xi\). For the quadratic element \(x_{\mathrm{m}} = h/2\), and the shape functions in \(\xi\) are \(N_1 = \xi(\xi - 1)/2\), \(N_2 = 1 - \xi^2\), \(N_3 = \xi(\xi + 1)/2\) (ONATE1 (3.11), PDF p. 103), which on substituting \(x = h(1 + \xi)/2\) into equation (7.24) gives exactly the functions \(\psi_{\mathrm{i}}\). The derivative with respect to \(x\) is \(\psi_{\mathrm{i}}' = \tfrac2h\,N_{\mathrm{i}}'\), where the prime denotes the derivative with respect to \(\xi\), so by equation (7.28)

\[\begin{aligned} k_{\mathrm{ij}} &= \int_0^h EA\,\psi_{\mathrm{i}}'\,\psi_{\mathrm{j}}'\,\mathrm{d}x = \frac{2\,EA}{h} \int_{-1}^{1} N_{\mathrm{i}}'\,N_{\mathrm{j}}'\,\mathrm{d}\xi , \\ N_1' &= \xi - \tfrac12 , \quad N_2' = -2\xi , \quad N_3' = \xi + \tfrac12 . \end{aligned} \tag{7.29}\]

The integrands are polynomials of degree two in \(\xi\).

Now the sum. Take a function \(g\) on \([-1, 1]\) and points \(\xi_1, \dots, \xi_{\mathrm{q}}\) with weights \(w_1, \dots, w_{\mathrm{q}}\). The simplest demand is that the sum \(\sum w_{\mathrm{i}}\,g(\xi_{\mathrm{i}})\) gives the true integral for as many powers \(1, \xi, \xi^2, \dots\) as possible. Since we can choose \(q\) points and \(q\) weights, we have \(2q\) free numbers, and with \(2q\) equations we can demand exactness for the powers from \(\xi^0\) to \(\xi^{2q-1}\). For \(q = 1\) the first equation (\(\xi^0\)) gives \(w_1 = 2\), the point is \(\xi_1 = 0\) by symmetry, and \(\xi^1\) is already satisfied. For \(q = 2\) we take the points \(\pm a\) with equal weights \(w\). For \(\xi^0\) we have \(2w = 2\), so \(w = 1\), and for \(\xi^2\) we have \(2a^2 = \tfrac23\), so \(a = 1/\sqrt3\). For \(q = 3\) we take the points \(0\) and \(\pm b\) with weights \(w_0\) and \(w_1\). For \(\xi^0\) we have \(w_0 + 2w_1 = 2\), for \(\xi^2\) we have \(2w_1 b^2 = \tfrac23\), and for \(\xi^4\) we have \(2w_1 b^4 = \tfrac25\). The quotient of the last two gives \(b^2 = \tfrac35\), then \(w_1 = \tfrac59\) and \(w_0 = \tfrac89\).

Definition 7.24 Gauss quadrature (Gaussovo pravilo)

Gauss quadrature with \(q\) points (Gaussovo pravilo s \(q\) točkami) is a rule that replaces the integral of a function \(g\) on \([-1, 1]\) by the weighted sum

\[\int_{-1}^{1} g(\xi)\,\mathrm{d}\xi \approx \sum_{\mathrm{i}=1}^{q} w_{\mathrm{i}}\,g(\xi_{\mathrm{i}}) , \tag{7.30}\]

where \(\xi_{\mathrm{i}} \in [-1, 1]\) are points (Gauss points, Gaussove točke) and \(w_{\mathrm{i}}\) are numbers (weights, uteži). For \(q = 1, 2, 3\) the points and weights are

  1. \(q = 1\): the point \(0\) with weight \(2\),
  2. \(q = 2\): the points \(\pm 1/\sqrt3\) with weights \(1\) and \(1\),
  3. \(q = 3\): the points \(0\) and \(\pm\sqrt{3/5}\) with weights \(8/9\) and \(5/9\).

Source: ONATE1 (3.40), PDF p. 113, and table 3.1, PDF p. 114, which lists the points and weights for \(q = 1, \dots, 8\) in decimal form, for example \(0{,}5773502692 = 1/\sqrt3\) and \(0{,}5555555556 = 5/9\). The derivation of the values from the equations for the powers is ours.

The rule makes sense only if it is exact for the integrands for which we chose it. The lemma says this.

Lemma 7.25 Exactness of Gauss quadrature (točnost Gaussovih pravil)

Let \(q \in \{1, 2, 3\}\). Gauss quadrature with \(q\) points (definition 7.24) gives the exact integral for every polynomial \(g\) of degree at most \(2q - 1\), \(\int_{-1}^{1} g\,\mathrm{d}\xi = \sum_{\mathrm{i}} w_{\mathrm{i}}\,g(\xi_{\mathrm{i}})\). For \(g = \xi^{2q}\) the sum does not give the integral.

Proof

We must show that equality holds for every power up to \(\xi^{2q-1}\), and then that it fails at \(\xi^{2q}\).

  1. By lemma 3.39, item 1, the integral is linear in \(g\), and the weighted sum is linear in \(g\) as a sum of products. Every polynomial of degree at most \(2q - 1\) is a linear combination of the powers \(1, \xi, \dots, \xi^{2q-1}\), so it suffices to check these powers.
  2. Odd powers: \(\int_{-1}^{1}\xi^m\,\mathrm{d}\xi = \big[\xi^{m+1}/(m+1)\big]_{-1}^{1} = 0\) by theorem 3.40. The points of all three rules are symmetric about \(0\) with equal weights on the pairs \(\pm\xi_{\mathrm{i}}\), so the terms \(w_{\mathrm{i}}\,\xi_{\mathrm{i}}^m\) and \(w_{\mathrm{i}}\,(-\xi_{\mathrm{i}})^m\) cancel and the sum is zero.
  3. Even powers, where the integral is \(2/(m+1)\). For \(q = 1\) we have \(m = 0\) and \(2 \cdot 1 = 2\). For \(q = 2\) we have \(m = 0\) and \(1 + 1 = 2\), and \(m = 2\) gives \(2 \cdot \tfrac13 = \tfrac23\). For \(q = 3\) we have \(m = 0\) and \(\tfrac59 + \tfrac89 + \tfrac59 = 2\), \(m = 2\) and \(2 \cdot \tfrac59 \cdot \tfrac35 = \tfrac23\), and \(m = 4\) and \(2 \cdot \tfrac59 \cdot \tfrac9{25} = \tfrac25\).
  4. At the next even power the sum fails. For \(q = 1\) it is \(\xi^2\) and the sum is \(2 \cdot 0 = 0\) instead of \(\tfrac23\). For \(q = 2\) it is \(\xi^4\) and the sum is \(2 \cdot \tfrac19 = \tfrac29\) instead of \(\tfrac25\). For \(q = 3\) it is \(\xi^6\) and the sum is \(2 \cdot \tfrac59 \cdot \tfrac{27}{125} = \tfrac6{25}\) instead of \(\tfrac27\).

Source: The proof is not from a source. ONATE1, PDF p. 113: a rule of order \(q\) integrates a polynomial of degree \(2q - 1\) exactly.

The proof showed that the rules satisfy all \(2q\) equations for the powers up to \(\xi^{2q-1}\) and that at the next power they fail, as we expect, since they have only \(2q\) free numbers. For larger \(q\) the same is claimed by ONATE1 (PDF p. 113), and table 3.1 (PDF p. 114) lists the points and weights up to \(q = 8\), but no result of this chapter rests on more than three points. What this means is shown by figure 7.12: a cubic polynomial and the line through its values at the two Gauss points have the same area, because the differences above and below the line are equal in size. The line through the values \(g(\pm 1/\sqrt3)\) has area \(g(-1/\sqrt3) + g(1/\sqrt3)\), which is exactly the sum with weights \(1\) and \(1\).

We apply the rule to the element matrix. By equation (7.29), \(k_{11} = \tfrac{2EA}{h}\int_{-1}^1 (\xi - \tfrac12)^2\,\mathrm{d}\xi\), the integrand has degree 2, and by lemma 7.25 the two-point rule (\(2q - 1 = 3 \ge 2\)) is exact. The sum is \((\tfrac1{\sqrt3} - \tfrac12)^2 + (-\tfrac1{\sqrt3} - \tfrac12)^2 = 2\,(\tfrac13 + \tfrac14) = \tfrac76\), so \(k_{11} = \tfrac{2EA}{h}\cdot\tfrac76 = \tfrac{7EA}{3h}\), as in lemma 7.23. The other entries are obtained in the same way (ONATE1, example 3.3, PDF pp. 118 and 119, the same computation for \(K_{11}^{(e)}\) with two points). Three points also give the same matrix (SymPy), but it is unnecessary work.

What if we take fewer points? One point, \(\xi_1 = 0\) with weight \(2\), saves work. The strain at this point is \(u_{\mathrm{h}}' = (2/h)\,(N_1'(0)\,d_1 + N_2'(0)\,d_2 + N_3'(0)\,d_3) = (d_3 - d_1)/h\), and by equation (7.29)

\[\mat k_{\mathrm{e}}^{(1)} = \frac{EA}{h} \begin{pmatrix} 1 & 0 & -1 \\ 0 & 0 & 0 \\ -1 & 0 & 1 \end{pmatrix} , \qquad \vek d_{\mathrm{e}}^{\mathsf T}\mat k_{\mathrm{e}}^{(1)}\vek d_{\mathrm{e}} = \frac{EA}{h}\,(d_3 - d_1)^2 . \tag{7.31}\]

The energy is zero also for \(\vek d_{\mathrm{e}} = (0, 1, 0)\), when only the middle node moves, although this is not a rigid shift. The field is then \(u_{\mathrm{h}} = \psi_2\) (figure 7.13), the strain \(\psi_2' = (4h - 8x)/h^2\) is \(\pm 4/h\) at the ends and zero only in the middle, where the one-point rule looks at it alone. The matrix \(\mat k_{\mathrm{e}}^{(1)}\) is symmetric and positive semidefinite (definition 7.15), so by lemma 7.16 \(\mat k_{\mathrm{e}}^{(1)}\vek d_{\mathrm{e}} = \vek 0\), and indeed the row of the middle node contains nothing. This is a spurious zero-energy mode (lažni način brez energije), also called an internal mechanism (notranji mehanizem): a motion of the element that is not rigid and that the matrix does not detect.

What does this mean for the computation? Take the hanging bar of this section with one element, but with the one-point rule. The forces of the element stay \((10{,}016, 40{,}065, 10{,}016)\) N, because we change only the integration of the stiffness. After striking out the fixed upper node the system is

\[\frac{EA}{h} \begin{pmatrix} 0 & 0 \\ 0 & 1 \end{pmatrix} \begin{pmatrix} d_2 \\ d_3 \end{pmatrix} = \begin{pmatrix} 40{,}065 \\ 10{,}016 \end{pmatrix}\ \text{N} . \tag{7.32}\]

The row of the middle node says \(0 = 40{,}065\) N: the system has no solution, because the matrix does not hold the middle node. If we left it unloaded, the system would have infinitely many solutions, since \(d_2\) would be arbitrary. One point is therefore not enough for an integrand of degree 2. We choose the number of points from the degree of the integrand, which for a quadratic element with constant stiffness means at least two, and then there is no spurious mode (lemma 7.23). ONATE1 (PDF pp. 130 and 131) warns that incomplete integration (reduced integration, nepopolno integriranje) can introduce undesirable internal mechanisms in addition to the rigid motions, that an element is stable if the stiffness matrix is integrated exactly, and that the eigenvalues must be checked on a single element and on a group of elements.

7.4.3 How fast we approach (kako hitro se približamo)

For the self weight of the hanging bar we saw that one quadratic element gives the exact field, because the true field is quadratic. This load therefore does not tell how fast the quadratic element approaches when the field is not quadratic. Take the same bar (\(L = 10\) m, \(EA = 1{,}5394 \cdot 10^7\) N, fixed at the top, free at the bottom, axis \(x\) pointing down) and the same total load \(60{,}10\) N, but distribute it linearly: zero at the top, \(q_{\mathrm{L}} = 12{,}02\) N/m at the bottom, \(q(x) = q_{\mathrm{L}}\,x/L\). This is not a physical case but a test, chosen so that the true field is not in the trial space of the quadratic element. The axial force is \(N = \int_{\mathrm{x}}^L q\,\mathrm{d}t = q_{\mathrm{L}}\,(L^2 - x^2)/(2L)\), and the displacement is

\[u(x) = \frac{q_{\mathrm{L}}}{2\,EA\,L}\,\Big(L^2 x - \frac{x^3}{3}\Big) , \tag{7.33}\]

a cubic polynomial, equal to \(26{,}03\) µm at \(x = L\) and \(17{,}89\) µm in the middle, with strain energy \(625{,}65\) µJ and \(N(0) = 60{,}10\) N.

We compare the linear and the quadratic element on meshes with \(n = 1, 2, 4, 8, 16\) equal elements. The measure of the error is the energy of the error \(\Pi(u_{\mathrm{h}}) - \Pi(u) = \tfrac12\,\|u - u_{\mathrm{h}}\|_{\mathrm{E}}^2\) (theorem 6.34), which chapter 6 used for the linear element. The values are computed with the element matrices of lemma 7.5 and lemma 7.23 and with consistent forces (SymPy and NumPy). The element matrices are assembled by theorem 7.13, whose item 3 (equality with the Ritz matrix) is proved for hat functions. Steps 4 and 5 of its proof use that the function of a node is a line on an element, determined by two values, so for quadratic elements we must replace these two steps. The function of a node is here continuous, quadratic on each element, \(1\) at its own node and \(0\) at all others, which is a shape function of the mesh (oblikovna funkcija mreže). The lemma says that on an element it equals one of the three shape functions of the element or zero.

Lemma 7.26 Shape functions of a mesh of quadratic elements (oblikovne funkcije mreže kvadratnih elementov)

Let a bar have a mesh of \(n_{\mathrm{e}}\) quadratic elements, each with nodes at \(x_{\mathrm{a}}\), \(x_{\mathrm{m}} = (x_{\mathrm{a}} + x_{\mathrm{b}})/2\) and \(x_{\mathrm{b}}\), and let neighbouring elements share an end node. Let \(g_{\mathrm{ei}}\) be the connectivity table with \(m = 3\) columns (definition 7.10) and \(I\) the number of an unknown, that is, of a node. Then there is exactly one continuous function \(\psi_{\mathrm{I}}\) on the bar that is a quadratic polynomial on each element, equal to \(1\) at node \(I\) and to \(0\) at all other nodes. On element \(e\) we have \(\psi_{\mathrm{I}} = \psi^e_{\mathrm{i}}\) if \(I = g_{\mathrm{ei}}\), and \(\psi_{\mathrm{I}} = 0\) if \(I\) is not in row \(e\) (the shape functions of the element \(\psi^e_{\mathrm{i}}\) of equation (7.24), shifted to \([x_{\mathrm{a}}, x_{\mathrm{b}}]\)).

Proof

We must show that a quadratic polynomial on an element is determined by its values at the three nodes, and then that the pieces assembled from these values fit together continuously.

  1. Let \(p\) be a quadratic polynomial on \([x_{\mathrm{a}}, x_{\mathrm{b}}]\) with \(p(x_{\mathrm{a}}) = p(x_{\mathrm{m}}) = p(x_{\mathrm{b}}) = 0\). From \(p(x_{\mathrm{a}}) = 0\) we get \(p = (x - x_{\mathrm{a}})(\alpha x + \beta)\), from \(p(x_{\mathrm{b}}) = 0\) we get \(\alpha x_{\mathrm{b}} + \beta = 0\), so \(p = \alpha\,(x - x_{\mathrm{a}})(x - x_{\mathrm{b}})\), and from \(p(x_{\mathrm{m}}) = 0\) we get \(\alpha\,(x_{\mathrm{m}} - x_{\mathrm{a}})(x_{\mathrm{m}} - x_{\mathrm{b}}) = -\alpha h^2/4 = 0\) with the element length \(h = x_{\mathrm{b}} - x_{\mathrm{a}}\), so \(\alpha = 0\) and \(p = 0\).
  2. Let \(r\) be an arbitrary quadratic polynomial on the element. The polynomial \(r - \sum_{\mathrm{i}} r(x^e_{\mathrm{i}})\,\psi^e_{\mathrm{i}}\) is quadratic and by the definition of the shape functions has the value zero at all three nodes, so by step 1 it is zero. Every quadratic polynomial on the element is therefore \(\sum_{\mathrm{i}} r(x^e_{\mathrm{i}})\,\psi^e_{\mathrm{i}}\), determined by its values at the nodes.
  3. By step 2, \(\psi_{\mathrm{I}}\) must equal \(\sum_{\mathrm{i}} \psi_{\mathrm{I}}(x^e_{\mathrm{i}})\,\psi^e_{\mathrm{i}}\) on element \(e\). Its values at the nodes of the element are \(1\) at node \(I\) and \(0\) at the others, so this is \(\psi^e_{\mathrm{i}}\) for \(I = g_{\mathrm{ei}}\) and \(0\) if \(I\) is not in row \(e\). With this \(\psi_{\mathrm{I}}\) is uniquely determined on each element.
  4. The \(\psi_{\mathrm{I}}\) assembled in this way is continuous. In the interior of an element it is a quadratic polynomial, at a node shared by two elements both one-sided values are the same number (\(1\) or \(0\), depending on whether this is node \(I\)), and a middle node belongs to a single element. At node \(I\) the value is \(1\) and at the others \(0\) by the definition of the shape functions.

Source: The proof is not from a source. ONATE1, figure 3.4 (PDF p. 113): assembly of the global matrix from the contributions of elements with three nodes.

With the lemma we replace steps 4 and 5 of the proof of theorem 7.13 and the remaining steps stay as they are. Step 3 needs only that the integrand is continuous on each closed element, which a polynomial is. Steps 1, 2 and 6 to 9 use only lemma 7.12, which is written for an arbitrary number \(m\) of displacements of the element, and that the field on an element is \(\sum_{\mathrm{i}} d^e_{\mathrm{i}}\,\psi^e_{\mathrm{i}}\), which the lemma now gives. Item 3 of the theorem therefore holds also for quadratic elements with a connectivity table of three columns, with the matrices \(\mat Z_{\mathrm{e}}\) having three rows.

The quotient is the ratio of the energy of the error at the previous mesh and at this one, that is, when \(h\) is halved. What does the table say? First, the displacements of all nodes are exact in all rows (the largest error is below \(10^{-17}\) m). For the nodes at the ends of elements this is given by theorem 6.38: the unit-force field at such a node is continuous and a line on each element, a line is a quadratic polynomial, so the field lies in the trial space of quadratic elements. For the middle nodes the theorem is silent, because the unit-force field at them has a kink in the middle of an element. That they are exact here too is said by the lemma that follows the table. Second, the energy of the error falls for the linear element with a quotient that approaches \(4 = 2^2\) (theorem 6.41 guarantees an upper bound proportional to \(h^2\), and we explain the quotient itself after the table), and for the quadratic element with a quotient \(16 = 2^4\), equal to \(16{,}00\) in all four places. Third, for the same number of unknowns the quadratic element is much better. With \(8\) unknowns the error of the linear one is \(2{,}0302\) µJ and of the quadratic one \(0{,}025458\) µJ, so about \(80\) times smaller, with \(16\) unknowns \(0{,}50876\) against \(0{,}0015910\) µJ, \(320\) times. A row of the matrix has up to five nonzero entries for the quadratic element instead of three, so there is somewhat more computation, but considerably fewer unknowns for the same accuracy. ONATE1 (PDF p. 124) says the same: the quadratic rod is better than the linear one, but for more demanding models, particularly three-dimensional ones, the improvement is offset by a more demanding mesh and a more expensive computation, so the choice is judged for each model separately. Fourth, the reaction is the same in all rows, \(-60{,}097\) N, the weight of the bar, while the axial force at the top is not: the linear element underestimates it (\(40{,}06\) against \(60{,}10\) N at \(n = 1\)), the quadratic one overestimates it (\(70{,}11\) N). The reason is the same as for the linear element in section 6.7.2. The reaction is determined by the equilibrium of the whole bar (lemma 7.20), and the axial force at the top is the derivative of the approximation at one point. The quadratic element again does not compute it exactly, although it comes closer: the error is \(+10{,}0\) N at \(n = 1\) and \(+0{,}04\) N at \(n = 16\). EP, example 8.2.1 (p. 548), notices the same for a composite bar with two quadratic elements: the force at the end, computed from the derivative of the field, is wrong by \(8{,}71\,\%\), while the force from the first equation of the system is exact.

Why exactly \(16\), and why are the middle displacements exact? For this load the true field is a cubic polynomial, so the error can be computed.

Lemma 7.27 Error of the quadratic element for a cubic field (napaka kvadratnega elementa pri kubičnem polju)

Let the bar be fixed at \(x = 0\), with axial stiffness \(EA\), constant, and let the solution of the weak form \(u\) be a cubic polynomial with third derivative \(u'''\). Let \(u_{\mathrm{h}}\) be the Ritz solution in the family of continuous fields that are \(0\) at \(x = 0\) and quadratic on each of \(n\) elements of length \(h = L/n\). On each element with midpoint \(x_{\mathrm{m}}\) and \(s = x - x_{\mathrm{m}}\) the error is \(u - u_{\mathrm{h}} = \tfrac16\,u'''\,s\,(s^2 - h^2/4)\). Therefore \(u_{\mathrm{h}}\) is exact at the midpoint of every element, and the energy of the error is \(\Pi(u_{\mathrm{h}}) - \Pi(u) = EA\,(u''')^2\,L\,h^4/1440\).

Proof

We must show that the error is a cubic polynomial that has zeros at the end points and is orthogonal to the hump of the middle node, and that this determines everything.

  1. The error \(e = u - u_{\mathrm{h}}\) on an element is the difference of a cubic and a quadratic polynomial, so a cubic polynomial with third derivative \(e''' = u'''\). At the end points of the element \(e = 0\) by theorem 6.38: the unit-force field at a node is continuous and a line on each element (the stiffness is constant), so a quadratic polynomial, and therefore it lies in the family. Let \(e = e_0 + e_1 s + e_2 s^2 + e_3 s^3\). The condition \(e(\pm h/2) = 0\) for each sign gives (the sum and the difference of the two) \(e_0 + e_2 h^2/4 = 0\) and \(e_1 + e_3 h^2/4 = 0\), so \(e = e_2\,(s^2 - h^2/4) + e_3\,s\,(s^2 - h^2/4) = (s^2 - h^2/4)(a\,s + b)\) with \(a = e_3\) and \(b = e_2\).
  2. From \(e''' = 6a\) and \(e''' = u'''\) we get \(a = u'''/6\).
  3. The shape function of the middle node, \(\psi_2 = 1 - 4s^2/h^2\) on this element and zero elsewhere, is continuous and quadratic on each element, so it is a trial field. By lemma 6.36, \(B(e, \psi_2) = EA \int e'\,\psi_2'\,\mathrm{d}x = 0\).
  4. The derivative of the error is \(e' = 3a\,s^2 + 2b\,s - a\,h^2/4\), and \(\psi_2' = -8s/h^2\). In the product the terms with \(s^3\) and \(s\) are odd and their integral over \([-h/2, h/2]\) is zero, what remains is \(\int e'\,\psi_2'\,\mathrm{d}s = -\tfrac{8}{h^2}\int_{-\mathrm{h}/2}^{h/2} 2b\,s^2\,\mathrm{d}s = -\tfrac{8}{h^2}\cdot\tfrac{b\,h^3}{6} = -\tfrac43\,b\,h\). From step 3, \(b = 0\).
  5. With \(b = 0\) we have \(e = a\,s\,(s^2 - h^2/4)\), and at the middle \(s = 0\) we have \(e = 0\).
  6. The energy of the error on an element is \(\tfrac12\,EA\int e'^2\,\mathrm{d}x = \tfrac12\,EA\,a^2\int_{-\mathrm{h}/2}^{h/2} (3s^2 - h^2/4)^2\,\mathrm{d}s = \tfrac12\,EA\,a^2\,h^5/20\) (SymPy) and \(a^2 = (u''')^2/36\), so \(EA\,(u''')^2\,h^5/1440\). Over \(n = L/h\) elements the sum is \(EA\,(u''')^2\,L\,h^4/1440\), and by theorem 6.34 this is \(\Pi(u_{\mathrm{h}}) - \Pi(u)\).

Source: The proof is not from a source.

The proof showed that the error is a cubic polynomial with zeros at the end points and in the middle, whose size is determined by \(u'''\), and that the energy of the error is proportional to \(h^4\). A check: for the test load \(u''' = -q_{\mathrm{L}}/(EA\,L)\), and for \(n = 1\) the formula gives \(EA\,(u''')^2\,L\,h^4/1440 = 6{,}5172\) µJ, as in the table, and for \(n = 2\) a sixteenth of it, \(0{,}40732\) µJ. The quotient \(16\) is therefore no accident but \(h^4\), and for this load it is exact.

For the linear element we do not get the quotient \(4\) exactly (\(3{,}37\), \(3{,}85\), \(3{,}96\), \(3{,}99\)), because the energy of the error there is the sum of a term with \(h^2\) and a term with \(h^4\). We derive them. The nodal values are exact (theorem 6.38), so on an element \([x_{\mathrm{a}}, x_{\mathrm{a}} + h]\) the derivative \(u_{\mathrm{h}}'\) is constant and equal to \((u(x_{\mathrm{a}} + h) - u(x_{\mathrm{a}}))/h\), which is the mean of the true derivative \(u'\) over the element (theorem 3.40). The energy of the error of an element is \(\tfrac12\,EA\int (u' - u_{\mathrm{h}}')^2\,\mathrm{d}x\). For the test load \(u' = q_{\mathrm{L}}\,(L^2 - x^2)/(2\,EA\,L)\) is a quadratic polynomial, and SymPy gives \(h^3 q_{\mathrm{L}}^2\,(4h^2 + 15\,h\,x_{\mathrm{a}} + 15\,x_{\mathrm{a}}^2)/(360\,EA\,L^2)\) for this integral. The sum over the elements \(x_{\mathrm{a}} = 0, h, \dots, (n-1)h\) with \(nh = L\) is

\[\begin{aligned} \Pi(u_{\mathrm{h}}) - \Pi(u) &= \frac{q_{\mathrm{L}}^2\,L}{72\,EA}\,h^2 - \frac{q_{\mathrm{L}}^2}{360\,EA\,L}\,h^4 \\ &= 1{,}3034\,h^2 - 0{,}002607\,h^4\ \text{µJ} , \end{aligned} \tag{7.34}\]

where \(h\) is in metres. The values in the table agree in all the digits written (at \(n = 1\), \(130{,}34 - 26{,}07 = 104{,}27\) µJ). Since the second term falls faster, the quotient approaches \(4\) as \(h\) is reduced.

For a general smooth field, however, this book does not prove the law \(h^4\) for quadratic elements. It is claimed by BATHE in section 4.3.5 (PDF pp. 263 to 265): for elements with polynomials of degree \(k\) the error in the energy norm (4.101) is proportional to \(h^k\), so the energy to \(h^{2k}\), for \(k = 2\) to \(h^4\). BATHE states the estimate of the interpolation error (4.100), on which this rests, as a known result of interpolation theory without a proof, and compares the measured order \(3{,}91\) with the theoretical \(4\) (PDF p. 265). This book has an interpolation estimate only for a line (lemma 6.40), so the law \(h^4\) is here proved for the cubic field (lemma 7.27) and for the quartic field that follows it is supported by computation.

Is the midpoint exact also for a field that is not a cubic polynomial? A check with a polynomial of degree four, again with quadratic elements: the load \(q = 3q_0\,(x/L)^2\) (\(q_0 = 6{,}0097\) N/m, in total again \(q_0 L = 60{,}10\) N) gives an end displacement of \(29{,}28\) µm, which is exact for all \(n\). The errors at the middle of the first element are, however, \(0{,}122\) µm (\(n = 1\)), \(0{,}00762\) µm (\(n = 2\)) and \(0{,}000477\) µm (\(n = 4\)), so they are not zero, and they fall with the quotient \(16\) (SymPy). The exactness of the midpoint is therefore a property of cubic fields, in which the error on an element is by the lemma odd about the middle of the element, not a property of the element. Figure 7.14 shows the difference for the same number of unknowns.

The figure shows the same content as the table. For one quadratic element and two linear ones the unknowns are the same, and the error is almost three times smaller (the largest \(0{,}63\) against \(1{,}84\) µm), and the energy of the error \(4{,}75\) times (\(6{,}5172\) against \(30{,}957\) µJ). With more elements the difference grows: with each halving the energy of the linear one is reduced by \(4\) and of the quadratic one by \(16\) (figure 7.15).

For a load that varies along the bar, the quadratic element therefore gives, for the same number of unknowns, an error that is \(80\) times smaller with \(8\) unknowns and \(320\) times smaller with \(16\). For the truss in section 7.5, where the loads are only at the nodes, the true axial force in each bar is constant, so one linear element per bar suffices and the quadratic element brings no improvement.
