Chapter 17 FEM modeling in practice

17.5 Mesh quality (kakovost mreže)

Until now we have always put the middle node of the quadratic bar element at the centre. Programs allow the node to be moved: so that an element fits a curved boundary, so that elements crowd where the stress is of interest, or simply because the mesh generator brought it along. What happens to the field and to the strain on an element if the node is moved? How far can we go before an element stops being an element? And can the same number of elements give a smaller error if we only arrange them differently? This section treats the discretization error (definition 17.2), more precisely its dependence on the shape and arrangement of the elements. It does not reduce the model error or the numerical error: a pretty mesh with a wrong model gives the exact solution of the wrong problem. We first find the mechanism for the bar, where we can prove everything, and then say what of it remains in the plane and in space.

17.5.1 The map of an element

The test element is the quadratic bar element of section 7.4 with axial stiffness \(EA\), constant along the element. We write its length \(L\) (in the section on convergence we write \(h\) for the element size in a mesh, and the letter \(H\) is the section height from the chapter on beams). The nodes 1 and 3 are at the ends, \(x_1 = 0\) and \(x_3 = L\), and the middle node 2 is at \(x_2 = c\,L\) with a fraction \(0 < c < 1\). The letter \(c\) here means the position of the node, while in the chapter on waves it means the wave speed. Figure 17.15 shows four such elements, drawn one below the other between the vertical lines \(0\) and \(L\). The top element has the middle node at the centre, \(c = 0{,}5\), as in section 7.4. The next two have the node moved towards the left end, \(c = 0{,}4\) and \(c = 0{,}3\), and the bottom one has it at a quarter of the length, \(c = 0{,}25\).

How do we write the field on such an element at all? In section 7.4 we mapped the element to \([-1, 1]\) with \(x = x_{\mathrm{m}} + \xi\,h/2\) and wrote the shape functions \(N_1 = \xi(\xi - 1)/2\), \(N_2 = 1 - \xi^2\), \(N_3 = \xi(\xi + 1)/2\) in the reference coordinate \(\xi\). Each equals \(1\) in its own node \(\xi = -1, 0, 1\) and zero in the other two. We took that map to be a straight line because the middle node was at the centre. Now we use the same functions for the position of a point. The point \(\xi\) of the reference element lies at

\[x(\xi) = N_1(\xi)\,x_1 + N_2(\xi)\,x_2 + N_3(\xi)\,x_3 = L\Big(c + \frac{\xi}{2} + \big(\tfrac12 - c\big)\,\xi^2\Big) , \tag{17.18}\]

and the field has the value \(U(\xi) = N_1 d_1 + N_2 d_2 + N_3 d_3\) there. The same set of functions describes the geometry and the field, so the element is called isoparametric (izoparametrični): geometry and field have the same number of parameters, in every node one datum of position and one datum of displacement (COOK, section 6.1, PDF p. 217). At \(c = \tfrac12\) we have \(x(\xi) = L(1 + \xi)/2\) and recover the old map. For other \(c\) the function \(x(\xi)\) contains a term in \(\xi^2\) and in the middle part of the figure the map is curved: pieces of equal length in \(\xi\) lie on the element at different distances from each other.

To compute the strain and the integrals we need how much length of the element falls on a unit of \(\xi\). That is the derivative of the map.

Definition 17.20 Jacobian of an element (Jacobijeva funkcija elementa)

Let a bar element have the nodes \(x_1 = 0\), \(x_2 = c\,L\), \(x_3 = L\) and \(0 < c < 1\). The element map (preslikava elementa) is the function \(x : [-1, 1] \to \mathbb{R}\) that assigns to every number \(\xi\) the number \(x(\xi)\) by equation (17.18). The Jacobian of the element (Jacobijeva funkcija elementa) is its derivative, the function \(J : [-1, 1] \to \mathbb{R}\),

\[J(\xi) = x'(\xi) = L\Big(\frac12 + (1 - 2c)\,\xi\Big) . \tag{17.19}\]

Source: COOK, section 6.1, equations (6.1-3) to (6.1-6), PDF pp. 217 to 218: the same shape function for \(x\) and \(u\), \(J\) is the reciprocal of \(\mathrm{d}\xi/\mathrm{d}x\) and "may be called a Jacobian", the factor that says how much physical length belongs to a reference length. The computation of the derivative is ours.

The name has a reason. In several dimensions the element map is a function of several variables, its derivative is a matrix, and its determinant is the Jacobian determinant of theorem 4.51. For the bar the matrix is a single number, so the Jacobian function is simply \(x'(\xi)\). We write the letter \(J\) without an index (with an index, \(J_2\) marked the second invariant of the deviator in the chapter on stress). The figure shows that \(J\) is a straight line in \(\xi\), with the constant value \(J = L/2\) at \(c = 0{,}5\) and with a slope that grows as \(c\) moves away from \(\tfrac12\). At \(c = 0{,}25\) the line reaches zero at the left end.

What does \(J\) do to the strain and the stiffness matrix? Here lies the reason why it must be positive.

Lemma 17.21 Strain and integral through the element map (deformacija in integral po preslikavi elementa)

Let \(J(\xi) > 0\) for every \(\xi \in [-1, 1]\) (definition 17.20). Then:

  1. The map \(x\) is a strictly increasing bijection of \([-1, 1]\) onto \([0, L]\), so it has an inverse function \(\xi(x)\), which is differentiable at every interior point with \(\xi'(x) = 1/J(\xi(x))\).
  2. The element field \(u_{\mathrm{h}}(x) = U(\xi(x))\) has the strain \(u_{\mathrm{h}}'(x) = U'(\xi)/J(\xi)\) at the point \(x = x(\xi)\), where the prime on \(U\) means the derivative with respect to \(\xi\).
  3. For every continuous function \(g\) on \([0, L]\) we have \(\int_0^L g\,\mathrm{d}x = \int_{-1}^{1} g(x(\xi))\,J(\xi)\,\mathrm{d}\xi\).
  4. An entry of the stiffness matrix is \(k_{\mathrm{ij}} = \int_0^L EA\,\psi_{\mathrm{i}}'\,\psi_{\mathrm{j}}'\,\mathrm{d}x = EA \int_{-1}^{1} \dfrac{N_{\mathrm{i}}'(\xi)\,N_{\mathrm{j}}'(\xi)}{J(\xi)}\,\mathrm{d}\xi\), where \(\psi_{\mathrm{i}}(x) = N_{\mathrm{i}}(\xi(x))\).
Proof

We must show that a positive \(J\) makes the map invertible, and then change the variable in the derivative and in the integral.

  1. Let \(\xi_1 < \xi_2\). By the mean value theorem (theorem 1.84) \(x(\xi_2) - x(\xi_1) = J(\eta)\,(\xi_2 - \xi_1) > 0\) for some \(\eta \in (\xi_1, \xi_2)\), so \(x\) is strictly increasing. From equation (17.18), \(x(-1) = x_1 = 0\) and \(x(1) = x_3 = L\), because \(N_1(-1) = 1\) and \(N_3(1) = 1\) and the other two functions vanish at these points. By the lemma on the inverse function (lemma 8.8) \(x\) is a bijection onto \([0, L]\), and its inverse is differentiable at interior points with derivative \(1/x'(\xi) = 1/J\).
  2. By the chain rule (lemma 4.43), \(u_{\mathrm{h}}'(x) = U'(\xi(x))\,\xi'(x) = U'(\xi)/J(\xi)\).
  3. Let \(G\) be a primitive function of \(g\), which exists by theorem 3.40. By the chain rule \(\frac{\mathrm{d}}{\mathrm{d}\xi}\,G(x(\xi)) = g(x(\xi))\,J(\xi)\), and by the same theorem \(\int_{-1}^{1} g(x(\xi))\,J\,\mathrm{d}\xi = G(x(1)) - G(x(-1)) = G(L) - G(0) = \int_0^L g\,\mathrm{d}x\).
  4. By point 2, \(\psi_{\mathrm{i}}' = N_{\mathrm{i}}'/J\). We insert it into \(\int_0^L EA\,\psi_{\mathrm{i}}'\psi_{\mathrm{j}}'\,\mathrm{d}x\) and use point 3 with \(g = EA\,\psi_{\mathrm{i}}'\psi_{\mathrm{j}}'\): we get \(EA \int (N_{\mathrm{i}}'/J)(N_{\mathrm{j}}'/J)\,J\,\mathrm{d}\xi\), which is the claim.

Source: COOK, section 6.1, PDF pp. 218 to 219: the strain \((\mathrm{d}u/\mathrm{d}\xi)/J\) and the stiffness matrix with \(J\) in the denominator, which cannot easily be integrated in closed form, so it is computed by Gauss integration. The proof in steps is ours.

If \(c = \tfrac12\), then \(J = L/2\) is constant and the integrand in point 4 is a polynomial, as in section 7.4. For other \(c\) the \(J\) is in the denominator, the integrand is a rational function and the Gauss rule (definition 7.24) is no longer exact. The lemma therefore owes us a statement of when \(J > 0\) holds at all.

17.5.2 Where the middle node may be

The condition \(J > 0\) is a condition on \(c\). Since \(J\) is a straight line in \(\xi\), its two end values, which the figure shows at the edges of the right panel, are all we need to know.

Lemma 17.22 Admissible position of the middle node (dovoljena lega srednjega vozlišča)

Let a bar element have the nodes \(0\), \(c\,L\) and \(L\) with \(0 < c < 1\).

  1. \(J(-1) = L\,(2c - \tfrac12)\) and \(J(1) = L\,(\tfrac32 - 2c)\).
  2. \(J(\xi) > 0\) for every \(\xi \in [-1, 1]\) if and only if \(\tfrac14 < c < \tfrac34\).
  3. If \(c \le \tfrac14\) or \(c \ge \tfrac34\), then \(J\) has a zero \(\xi_0 = 1/(2(2c - 1))\) in \([-1, 1]\). For \(c < \tfrac14\) we have \(x(\xi_0) = L\,\big(c - 1/(8(1 - 2c))\big) < 0\) and \(x\) is not monotone: the same point of the bar has two values of \(\xi\) and the element sticks out over node 1.
Proof

We must show the end values of \(J\), that the positivity of a straight line is positivity at both ends, and find the zero.

  1. We insert \(\xi = \mp 1\) into equation (17.19): \(J(-1) = L(\tfrac12 - 1 + 2c)\) and \(J(1) = L(\tfrac12 + 1 - 2c)\).
  2. By equation (17.19) the function \(J\) is linear in \(\xi\), so each of its values on \([-1, 1]\) lies between \(J(-1)\) and \(J(1)\): for every \(\xi\) we have \(J(\xi) = \tfrac{1 - \xi}{2}\,J(-1) + \tfrac{1 + \xi}{2}\,J(1)\) (inserting point 1 gives equation (17.19)) with nonnegative weights whose sum is \(1\). If both end values are positive, every value is positive. Conversely, positivity at the ends is necessary. Point 1 turns \(J(-1) > 0\) into \(c > \tfrac14\) and \(J(1) > 0\) into \(c < \tfrac34\).
  3. From \(J(\xi_0) = 0\) and equation (17.19) we have \((1 - 2c)\,\xi_0 = -\tfrac12\), so \(\xi_0 = 1/(2(2c - 1))\). The condition \(|\xi_0| \le 1\) is \(|2c - 1| \ge \tfrac12\), that is \(c \le \tfrac14\) or \(c \ge \tfrac34\). For \(c < \tfrac14\) we have \(J(-1) < 0 < J(1)\), so \(x'\) changes sign at \(\xi_0\), where \(x\) has its smallest value. Inserting \(\xi_0\) into equation (17.18) gives \(x(\xi_0) = L\,(c - \tfrac{1}{4(1 - 2c)} + \tfrac{1}{8(1 - 2c)}) = L\,(c - \tfrac{1}{8(1 - 2c)})\).

Source: The proof is not from the source. COOK, PDF p. 250: "An acceptably shaped element should not display negative J at any Gauss point location."

The proof showed that the positivity of \(J\) is a question of two numbers and that at a quarter and three quarters of the length we are at the edge. Now a test that at the same time shows that the condition \(J > 0\) is not yet sufficient.

Example 17.23 Middle node off the centre, field \(u = x^2\) (premaknjeno vozlišče pri polju \(u = x^2\))

Take \(L = 1\) and the displacement \(u = x^2\) with the strain \(2x\), which grows from \(0\) to \(2\). The nodal values are \(d = (0, c^2, 1)\), and the element equals \(u\) everywhere where \(u_{\mathrm{h}} = x^2\). At \(c = \tfrac12\) the function \(x(\xi)\) is linear, so \(x(\xi)^2\) is a polynomial of degree two in \(\xi\), which \(N_1, N_2, N_3\) represent exactly (they have the same values in the nodes): \(u_{\mathrm{h}} = x^2\) and the strain is exact, the error is \(0\).

At \(c \ne \tfrac12\) the coefficient of \(\xi^4\) in \(x(\xi)^2\) is \((2c - 1)^2/4 \ne 0\) (SymPy), while the field \(U(\xi)\) has degree at most \(2\). Polynomials of degree \(4\) and \(2\) do not agree everywhere, so \(u_{\mathrm{h}} \ne x^2\). The largest strain error is at the left end, where the true \(2x = 0\). There \(U'(-1) = 2d_2 - d_3/2 = 2c^2 - \tfrac12\) and \(J(-1) = 2c - \tfrac12\), so by point 2 of lemma 17.21

\[u_{\mathrm{h}}'(0) = \frac{2c^2 - \frac12}{2c - \frac12} . \tag{17.20}\]

The numbers, computed with SymPy and NumPy, are:

\(c\) \(J(-1)/L\) largest strain error \(k_{11}\,L/EA\) exact with 2 points with 3 points
\(0{,}5\) \(0{,}50\) \(0\) \(2{,}3333\) \(2{,}3333\) \(2{,}3333\)
\(0{,}4\) \(0{,}30\) \(0{,}60\) \(3{,}1284\) \(3{,}0282\) \(3{,}1239\)
\(0{,}3\) \(0{,}10\) \(3{,}20\) \(5{,}5725\) \(4{,}3220\) \(5{,}2424\)
\(0{,}26\) \(0{,}02\) \(18{,}24\) \(10{,}7635\) \(5{,}2156\) \(7{,}5330\)

At \(c = 0{,}26\) we have \(J > 0\) by lemma 17.22, so the element is admissible, but the strain error is \(9\) times the largest true strain \(2\). Figure 17.16 shows the cause. On the left panel the strain is drawn above the axis \(x\) of the element. At \(c = 0{,}5\) it coincides with the true straight line \(2x\). For the other fractions the strain of the element oscillates near the left end far from the true straight line, because \(J\) is small in the denominator while \(U'(-1)\) in the numerator is not zero. The stiffness entry \(k_{11}\) is also computed ever worse: at \(c = 0{,}3\) the two-point rule misses by \(22\,\%\) and three points by \(6\,\%\), because the rational integrand with a small denominator rises sharply at the end (definition 7.24).

Positivity of \(J\) is thus a necessary condition for the element to exist, but not a sufficient condition for its quality. The measure of quality is how little \(J\) changes over the element: at \(c = 0{,}5\) not at all, at \(c = 0{,}26\) by a factor of \(49\), from \(J(-1)/L = 0{,}02\) to \(J(1)/L = 0{,}98\). Below the limit, at \(c = 0{,}2\), we have \(J(-1)/L = -0{,}10\), \(\xi_0 = -0{,}8333\) and \(x(\xi_0) = -0{,}00833\,L\) (lemma 17.22, point 3). So the element sticks out \(0{,}83\,\%\) of its length beyond the end of the bar. The strain has a pole inside, because at \(\xi_0\) the denominator \(J\) is zero while the numerator is not: for the nodal values of the field \(u = x^2\) of the example, \(U'(\xi_0) = -0{,}27\). A check of the sign of \(J\) at the Gauss points only does not always see this. With two points the left point \(\xi = -0{,}577\) has \(J/L = 0{,}15\), with three points the point \(\xi = -0{,}775\) has \(0{,}035\). Both are positive, because both points lie to the right of \(\xi_0\). Since \(J\) is a straight line, the reliable check is the sign at both ends (lemma 17.22, point 2).

17.5.3 The quarter-point (četrtinska točka)

We marked the limit \(c = \tfrac14\) as inadmissible, yet programs use it there on purpose. Figure 17.16 shows why: on the right panel the error of the field \(u_{\mathrm{h}} - \sqrt{x}\) at \(c = 0{,}25\) is exactly zero, while for other fractions it is up to \(0{,}14\) (at \(c = 0{,}5\)). An element with a quarter point represents the square root exactly. Why is the square root interesting? Because in a linearly elastic body with a crack the stress near the crack tip behaves like \(1/\sqrt r\), where \(r\) is the distance from the tip (COOK, section 8.7, PDF p. 298). If the strain is proportional to \(r^{-1/2}\), the displacement is by the fundamental theorem (theorem 3.40) proportional to \(2\sqrt r\). Ordinary elements cannot represent such a strain (ibid.). It turns out that an element with a moved node can.

Corollary 17.24 Quarter-point element (element s četrtinsko točko)

Let \(c = \tfrac14\) and \(s = \sqrt{x/L}\). Then:

  1. \(x(\xi) = L\,(1 + \xi)^2/4\), so \(\xi = 2s - 1\), and \(J(\xi) = L\,(1 + \xi)/2\) has a zero at \(\xi = -1\).
  2. The element field with displacements \(d_1, d_2, d_3\) is \(u_{\mathrm{h}} = d_1 + a\,s + b\,s^2\) with \(a = 4d_2 - 3d_1 - d_3\) and \(b = 2\,(d_1 - 2d_2 + d_3)\). For \(x > 0\) we have \(u_{\mathrm{h}}' = \dfrac{a}{2\sqrt{xL}} + \dfrac{b}{L}\).
  3. The field \(u = \sqrt{x/L}\) with displacements \((0, \tfrac12, 1)\) is represented exactly by the element (\(a = 1\), \(b = 0\)), and so are a constant field and the field \(u = x/L\) with displacements \((0, \tfrac14, 1)\) (\(a = 0\), \(b = 1\)).
Proof

We must show the map, the form of the field in \(s\) and three values.

  1. Inserting \(c = \tfrac14\) into equation (17.18) gives \(x = L(\tfrac14 + \tfrac\xi2 + \tfrac{\xi^2}4) = L(1 + \xi)^2/4\) and into equation (17.19) \(J = L(1 + \xi)/2\) (SymPy). Since \(1 + \xi \ge 0\) on the element, \(s = (1 + \xi)/2\).
  2. At \(\xi = 2s - 1\) we have \(N_1 = 2s^2 - 3s + 1\), \(N_2 = 4s - 4s^2\) and \(N_3 = 2s^2 - s\). The sum \(d_1N_1 + d_2N_2 + d_3N_3\) gives \(d_1 + a\,s + b\,s^2\) with the stated \(a\) and \(b\). The derivative follows by the chain rule (lemma 4.43) with \(s' = 1/(2\sqrt{xL})\) and \(b\,(s^2)' = b/L\).
  3. For \(\sqrt{x/L}\) the nodal values are \(0\), \(\sqrt{1/4} = \tfrac12\), \(1\), so \(a = 2 - 1 = 1\) and \(b = 2(0 - 1 + 1) = 0\), which is \(u_{\mathrm{h}} = s\). For \(x/L = s^2\) we have \(d = (0, \tfrac14, 1)\) and \(a = 0\), \(b = 2(-\tfrac12 + 1) = 1\), so \(u_{\mathrm{h}} = s^2\). A constant field \(d_{\mathrm{i}} = d\) gives \(a = b = 0\).

Source: COOK, section 8.7, equation (8.7-3) and the text, PDF pp. 298 to 299: for \(x \ll L\) the strain is inversely proportional to \(\sqrt x\), the element keeps rigid-body motion and constant strain. The proof in steps is ours.

The proof showed that the field \(u_{\mathrm{h}}\) contains \(\sqrt{x}\), \(x\) and a constant, and that the strain is unbounded whenever \(a \ne 0\). But unboundedness has a price, which in a book about the bar we must not conceal. Ritz's method (chapter 6) requires fields of finite energy (definition 6.18).

Lemma 17.25 Energy of the quarter-point element in one dimension (energija elementa s četrtinsko točko v eni razsežnosti)

At \(c = \tfrac14\) and \(a \ne 0\) from corollary 17.24, the energy \(\int_\delta^L EA\,(u_{\mathrm{h}}')^2\,\mathrm{d}x\) is unbounded as \(\delta \to 0\), namely \(\frac{EA\,a^2}{4L}\ln(L/\delta)\) plus a bounded term. Only the fields with \(a = 0\), that is with \(d_3 = 4d_2 - 3d_1\), have finite energy, and these are the straight lines \(u_{\mathrm{h}} = d_1 + b\,x/L\).

Proof

We must show the expansion of the square of the strain and the integral of each term.

  1. By corollary 17.24, \((u_{\mathrm{h}}')^2 = \dfrac{a^2}{4xL} + \dfrac{ab}{L\sqrt{xL}} + \dfrac{b^2}{L^2}\).
  2. By the fundamental theorem (theorem 3.40), \(\int_\delta^L \dfrac{1}{x}\,\mathrm{d}x = \ln\dfrac L\delta\), \(\int_\delta^L x^{-1/2}\,\mathrm{d}x = 2\,(\sqrt L - \sqrt\delta)\) and \(\int_\delta^L \mathrm{d}x = L - \delta\). The last two integrals are bounded for every \(\delta \in (0, L)\), the first exceeds every bound as \(\delta \to 0\).
  3. So the energy equals \(\frac{EA\,a^2}{4L}\ln\frac L\delta\) plus a bounded part, and it is unbounded if \(a \ne 0\). The condition \(a = 0\) is \(d_3 = 4d_2 - 3d_1\), and then \(u_{\mathrm{h}} = d_1 + b\,s^2 = d_1 + b\,x/L\).

Source: The proof is not from the source.

A test with numbers, the field \(u = \sqrt{x}\) (\(L = EA = 1\), \(d = (0, \tfrac12, 1)\), \(a = 1\), \(b = 0\)): the energy on \([\delta, 1]\) is \(1{,}15\), \(2{,}30\), \(3{,}45\) and \(4{,}61\) for \(\delta = 10^{-2}\), \(10^{-4}\), \(10^{-6}\), \(10^{-8}\) (SymPy). Every hundredfold smaller \(\delta\) adds \(1{,}15 = \tfrac14\ln 100\), as the lemma predicts with the factor \(\frac{EA\,a^2}{4L} = \tfrac14\). The field \(u = x\) (\(d = (0, \tfrac14, 1)\), \(a = 0\)) has the energy \(1 - \delta\), which is less than \(1\) for every \(\delta\). A program that computes the stiffness with the Gauss rule gets finite numbers, \(k_{11} = 5{,}5\) with two and \(8{,}5\) with three points (SymPy and NumPy). The two numbers differ, and the true value is infinite, because \(k_{11}\) is the energy of the field \(\psi_1\) with \(d = (1, 0, 0)\), which has \(a = -3 \ne 0\). Therefore the quarter point in a bar is a poor element: either it has infinite energy, or it represents only straight lines, which the linear element already does. For a plane element it is different. There we compute the energy over an area, where the area of an annulus of radius \(r\) grows with \(r\), and \(\varepsilon^2 \propto 1/r\) gives a finite integral. This remark is not proved in this book. COOK (PDF p. 300) states that quarter-point elements pass the patch test, so as the mesh is refined they approach the solution correctly, and plane elements are introduced in chapter 15. The quarter point is thus at once a defect (for a smooth field: at \(c = 0{,}26\) the strain error is \(18{,}24\) for a largest true strain of \(2\)) and a deliberate tool (for the field \(\sqrt{x}\)), and what decides is the field we are looking for, not the element.

17.5.4 How large should the elements be

We moved a node, now let us move the nodes of the mesh. The tube from the chapter on the boundary value problem (inner radius \(a = 40\) mm, outer \(b = 60\) mm) has by theorem 11.27 the radial displacement \(u(r) = C_1 r + C_2/r\) with second derivative \(u'' = 2C_2/r^3\). At \(r = 40\) mm it is \((60/40)^3 = 3{,}4\) times larger than at \(r = 60\) mm. A uniform mesh has the same element length everywhere, so a large error at the inner edge and a small one at the outer. Can we reach a smaller largest error with the same number of elements? The measure of error is given by lemma 6.40: on an element of length \(h_{\mathrm{e}}\) the error of linear interpolation is at most \(\tfrac18 h_{\mathrm{e}}^2 \mu_{\mathrm{e}}\), where \(\mu_{\mathrm{e}}\) is the largest \(|u''|\) on the element. The measure says how well the mesh can follow the field, not what the error of the solution is (that was stated in section 17.3).

Lemma 17.26 A mesh with equal bounds (mreža z enakimi mejami)

Let \(u\) have a continuous second derivative on \([a, b]\) and let \(u'' \neq 0\) everywhere. For a mesh \(a = r_0 < r_1 < \dots < r_{\mathrm{n}} = b\) with element lengths \(h_{\mathrm{e}} = r_{\mathrm{e}} - r_{\mathrm{e}-1}\) and \(\mu_{\mathrm{e}} = \max |u''|\) on \([r_{\mathrm{e}-1}, r_{\mathrm{e}}]\), let \(\beta_{\mathrm{e}} = \tfrac18 h_{\mathrm{e}}^2 \mu_{\mathrm{e}}\) be the bound from lemma 6.40, point 2, and \(\beta = \max_{\mathrm{e}} \beta_{\mathrm{e}}\). If there is a mesh \(A\) with \(n\) elements in which all bounds are equal, \(\beta_{\mathrm{e}} = \beta_{\mathrm{A}}\), then no other mesh with \(n\) elements has a smaller largest bound.

Proof

We must show that a mesh with a smaller largest bound would mean that \(n\) elements do not cover the interval.

  1. Let a mesh \(B\) with nodes \(s_0 = a, \dots, s_{\mathrm{n}} = b\) have the largest bound \(\beta_{\mathrm{B}} < \beta_{\mathrm{A}}\).
  2. We claim \(s_{\mathrm{k}} < r_{\mathrm{k}}\) for \(k = 1, \dots, n\). For \(k = 1\): if \(s_1 \ge r_1\), the first element of mesh \(B\) would contain the first element of mesh \(A\), so it would have \(h \ge h_1^A\) and \(\mu \ge \mu_1^A\) (the maximum over a larger interval is not smaller), hence \(\beta_1^B \ge \beta_{\mathrm{A}}\), a contradiction.
  3. Let \(s_{\mathrm{k}-1} < r_{\mathrm{k}-1}\). If \(s_{\mathrm{k}} \ge r_{\mathrm{k}}\), the element \(k\) of mesh \(B\) would contain \([r_{\mathrm{k}-1}, r_{\mathrm{k}}]\), again \(\beta_{\mathrm{k}}^B \ge \beta_{\mathrm{k}}^A = \beta_{\mathrm{A}}\), a contradiction. So \(s_{\mathrm{k}} < r_{\mathrm{k}}\).
  4. For \(k = n\) we get \(s_{\mathrm{n}} < r_{\mathrm{n}} = b\), which contradicts \(s_{\mathrm{n}} = b\).

Source: The proof is not from the source.

Example 17.27 Tube with eight elements (cev z osmimi elementi)

On \([40, 60]\) mm the \(|u''|\) is decreasing, so \(\mu_{\mathrm{e}} = |u''|\) at the left end of the element. The uniform mesh has \(h = 2{,}5\) mm and bounds from \(1{,}22\cdot 10^{-5}\,C\) at the inner edge to \(0{,}41\cdot 10^{-5}\,C\) at the outer, where \(C = 2|C_2|\). The mesh with equal bounds (step by step from \(r_0 = 40\) mm, SymPy and NumPy) has nodes at \(40\), \(41{,}906\), \(43{,}950\), \(46{,}146\), \(48{,}508\), \(51{,}054\), \(53{,}803\), \(56{,}776\) and \(60\) mm, elements between \(1{,}906\) and \(3{,}224\) mm, and everywhere the bound \(0{,}71\cdot 10^{-5}\,C\). The largest bound is \(1{,}72\) times smaller than for the uniform mesh (at \(n = 4\): \(1{,}59\) times, at \(n = 16\): \(1{,}79\) times). Figure 17.17 shows this above the radius \(r\) from \(40\) to \(60\) mm: for the uniform mesh the columns have different heights, for gradually larger elements all are equal and below the dashed level of the first mesh.

A test that limits the lemma: neighbouring elements differ by a factor from \(1{,}072\) to \(1{,}084\), so the change of size is not abrupt (COOK, PDF p. 355: abrupt changes of size are not recommended because they cause a disturbance in the field of gradients). But the bound is a measure for displacements. For the strain (the derivative, which in section 17.4 gives us the stress), point 1 of lemma 6.40 gives the bound \(h_{\mathrm{e}}\mu_{\mathrm{e}}\), and equal bounds require elements \(h_{\mathrm{e}} \propto 1/\mu_{\mathrm{e}}\) from \(1{,}498\) to \(4{,}090\) mm, a ratio of \(2{,}73\) instead of \(1{,}69\). A mesh adapted to displacements is therefore not the best for stresses: neighbouring elements differ at the strain bound by a factor of up to \(1{,}21\), and the mesh for displacements has a \(1{,}27\) times larger strain bound than the mesh for strains (the bounds are \(2{,}98\cdot 10^{-5}\,C\) and \(2{,}34\cdot 10^{-5}\,C\), the uniform mesh has \(3{,}91\cdot 10^{-5}\,C\)).

17.5.5 Plane and space

Everything we proved is one-dimensional. In the plane the element map is \((\xi, \eta) \mapsto (x, y)\), its derivative is a \(2 \times 2\) matrix and its determinant is the Jacobian determinant (chapter 15). The reasons are the same: changing the variable in an integral and in the strain needs an invertible map, that is a determinant that is nowhere zero. Figure 17.18 shows six shapes of a quadrilateral element that COOK lists as shapes that as a rule reduce accuracy (section 10.3, PDF pp. 354 to 355, section 6.11, PDF p. 250). Each time a good square is drawn next to it. The elongated element has a large aspect ratio \(a/b\), the skewed one has an angle \(\alpha\) far from \(90^\circ\), the tapered one has parallel sides \(a\) and \(b\) of different lengths, and the node on a side is moved off the centre, like our \(c\). The curved side has a sag \(s\). In the last element a corner is pushed over the diagonal between its neighbouring corners, so the angle at it is larger than \(180^\circ\) and \(J < 0\) there, as in our \(c < \tfrac14\).

What does this mean for the choice of mesh? COOK states: computed results are most accurate for compact elements with straight sides, and larger elongation, non-orthogonality, curvature of sides and offset of side nodes as a rule reduce accuracy (PDF p. 250), distortion spoils gradients, that is stresses, more than displacements, natural frequencies or temperatures (PDF p. 354), and the amount of spoiling depends on the kind of element, the arrangement of the mesh and the physical problem (ibid.), so there is no limit that would hold for all. An eight-node element loses exact bending if the angle departs from \(90^\circ\), the sides are curved or the side nodes are not at the midpoints (PDF p. 250), which is the plane version of our case \(c \ne \tfrac12\). An element with \(J < 0\) at some Gauss point is not acceptable, and programs check the shapes of the elements before the computation and may refuse to compute until the bad shapes are corrected (PDF p. 250). Mesh quality is thus two things: the shape of a single element (a checkable property, \(J > 0\) and reasonably constant) and the arrangement of sizes (lemma 17.26, abrupt changes are bad). For three-dimensional elements the warping of faces is added (COOK, PDF p. 355), here it is only named. How programs generate a mesh (advancing front, Delaunay triangulation) we do not treat here.

This section treated the discretization error. What the shape of the elements does to it we showed on the bar: moving the middle node from the centre does not change the number of elements, but at \(c = 0{,}26\) it makes the strain error \(9\) times the largest true strain, while the mesh with equal bounds lowers the largest bound \(1{,}72\) times with the same number of elements. The model error (\(c\) changed nothing in the model of the bar) and the numerical error (the conditioning of the stiffness matrix at small \(J\), treated in the section on large systems of equations) remain.
