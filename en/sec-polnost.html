Chapter 1 Strain

1.8 Mathematics: numbers without holes

At the end of the previous section we needed a statement about functions of one variable: the change of a function between two numbers equals the derivative at some point between them times the difference of the two numbers. On a picture of the graph it looks self-evident, but its proof depends on the fact that the number line has no holes. In this section we say what exactly this means and what follows from it. First we find a hole among the fractions. Then we give a name to the bound up to which a set of numbers reaches, so that we can describe the hole without the number that is missing. Then we require that the real numbers have no such holes, and from this requirement we derive the first consequences: how the elements of a set come close to its bound, that the natural numbers grow past every bound, and that every nonnegative number has a square root.

1.8.1 A hole among the fractions

To begin, some notation that we will use from now on. A set is made up of its elements (the definition of a function 1.4 speaks of sets and their elements). The notation \(x \in A\) means that \(x\) is an element of the set \(A\), and the notation \(A \subseteq B\) means that every element of the set \(A\) is also an element of the set \(B\). We write the set of all elements that satisfy some condition with curly brackets. So \(\{t \in \mathbb R : t^2 < 3\}\) is the set of all real numbers \(t\) whose square is less than \(3\). We write a finite set as the list of its elements, for example \(\{1, 2, 3\}\). A set that has no element is empty, and a set with at least one element is nonempty. The sign \(\mathbb R\) denotes the set of all real numbers, that is, of all points of the number line. The natural numbers are \(1, 2, 3, \dots\), and we write their set \(\mathbb N\). The integers \(\dots, -2, -1, 0, 1, 2, \dots\) form the set \(\mathbb Z\). A fraction, or rational number (racionalno število), is a number \(p/q\), where \(p\) and \(q\) are integers and \(q \neq 0\). We write the set of all fractions \(\mathbb Q\) (LEBL1 §0.3, PDF pp. 8-10).

About numbers we assume what we know from school. First, how we add, multiply, divide and compare them by size (LEBL1 Def. 1.1.5 and 1.1.7, PDF pp. 25-26, where these rules are collected as the rules of addition, multiplication and order). Second, two properties of the integers: an integer can be divided with a remainder, and every nonempty set of natural numbers has a smallest element (LEBL1 §0.3.2, PDF p. 12, which accepts this property without proof). Division with a remainder we know from school, and LEBL1 uses it without stating it. The rules of arithmetic from the first part also hold for fractions: the sum, difference, product and quotient of fractions are again fractions. So these rules do not tell the real numbers apart from the fractions. We will see that the fractions do differ from the real numbers after all, and exactly in the statement we need.

Take the function \(f(t) = t^3\) between the numbers \(0\) and \(1\) (figure 1.50). The line through the points of the graph above \(0\) and above \(1\) has the slope

\[\frac{f(1) - f(0)}{1 - 0} = \frac{1 - 0}{1} = 1 .\]

The statement we need says that somewhere between \(0\) and \(1\) a tangent also has the slope \(1\), that is, that there is a \(\xi\) between \(0\) and \(1\) with \(f'(\xi) = 1\). The Greek letter \(\xi\) (xi) denotes this point in between. For this we need the derivative of the function \(f\). Let us compute it by the definition of the derivative 1.9 at any point \(t\). First we simplify the difference quotient, as for the hanging bar in section 1.3.4.

  1. We expand the square of the sum: \((t + \Delta t)^2 = t^2 + 2t\,\Delta t + \Delta t^2\).
  2. The cube is the square multiplied once more by \(t + \Delta t\). We multiply each term of the square by \(t\) and by \(\Delta t\) and add the like terms:
    \[(t + \Delta t)^3 = (t^2 + 2t\,\Delta t + \Delta t^2)(t + \Delta t) = t^3 + 3t^2\,\Delta t + 3t\,\Delta t^2 + \Delta t^3 .\]
  3. We subtract \(f(t) = t^3\). The terms \(t^3\) cancel: \((t + \Delta t)^3 - t^3 = 3t^2\,\Delta t + 3t\,\Delta t^2 + \Delta t^3\).
  4. We divide by \(\Delta t \neq 0\). Every term has the factor \(\Delta t\), which cancels:
    \[\frac{(t + \Delta t)^3 - t^3}{\Delta t} = 3t^2 + 3t\,\Delta t + \Delta t^2 .\]

The candidate for the limit is \(3t^2\), the value of the right side at \(\Delta t = 0\). Lemma 1.26 on the limit of a number plus a multiple is not enough here, because the last term, \(\Delta t^2\), is not a multiple of the change \(\Delta t\) with a fixed factor. So we show the limit by the definition of the limit 1.5. It requires: for every \(\eta > 0\) there is a \(\delta > 0\) such that \(|(3t^2 + 3t\,\Delta t + \Delta t^2) - 3t^2| < \eta\) for every \(\Delta t\) with \(0 < |\Delta t| < \delta\).

  1. We pick any error \(\eta > 0\). The difference that the condition bounds is \((3t^2 + 3t\,\Delta t + \Delta t^2) - 3t^2 = 3t\,\Delta t + \Delta t^2 = \Delta t\,(3t + \Delta t)\).
  2. The absolute value of a product is the product of the absolute values (lemma 1.6, item 2): \(|\Delta t\,(3t + \Delta t)| = |\Delta t|\,|3t + \Delta t|\).
  3. By the triangle inequality for numbers \(|a + b| \le |a| + |b|\) (lemma 1.6, item 1) we have \(|3t + \Delta t| \le 3|t| + |\Delta t|\). Multiplying the inequality by the nonnegative number \(|\Delta t|\) keeps it: \(|\Delta t|\,|3t + \Delta t| \le |\Delta t|\,(3|t| + |\Delta t|)\).
  4. The factor \(3|t| + |\Delta t|\) changes with \(\Delta t\), so we first bound it by a fixed number. For \(|\Delta t| < 1\) we have \(3|t| + |\Delta t| < 3|t| + 1\). The number \(1\) is an arbitrary choice, and any positive number would do as well. So for \(0 < |\Delta t| < 1\) we have \(|\Delta t|\,(3|t| + |\Delta t|) < |\Delta t|\,(3|t| + 1)\).
  5. The last expression is smaller than \(\eta\) if \(|\Delta t| < \eta/(3|t| + 1)\). So for the band \(\delta\) we take the smaller of the numbers \(1\) and \(\eta/(3|t| + 1)\), which are both positive. For \(0 < |\Delta t| < \delta\) both requirements hold, \(|\Delta t| < 1\) and \(|\Delta t| < \eta/(3|t| + 1)\), and by steps 5 to 8
    \[|3t\,\Delta t + \Delta t^2| \le |\Delta t|\,(3|t| + |\Delta t|) < |\Delta t|\,(3|t| + 1) < \frac{\eta}{3|t| + 1}\,(3|t| + 1) = \eta .\]
  6. We picked the error freely and found a band for it. So the limit is \(3t^2\), and \(f'(t) = 3t^2\).

The tangent has the slope \(1\) where \(3\xi^2 = 1\), that is, \(\xi^2 = \tfrac13\). Between \(0\) and \(1\) this is the number \(\xi = 1/\sqrt 3 = 0{,}577\dots\) That such a real number really exists we will prove in section 1.8.6. Would this point exist if we knew only the fractions? Only if some fraction had the square \(\tfrac13\). Let us show that none has. It is enough to show that no fraction has the square \(3\). For if the fraction \(p/q\) had the square \(\tfrac13\), the fraction \(3p/q\) would have the square \(9 \cdot \tfrac13 = 3\).

That the side and the diagonal of a square have no common measure was, historians believe, proved already by the Pythagoreans. Two lengths have a common measure if there is a length that goes a whole number of times into the first and a whole number of times into the second. This discovery is said to have led the Greeks to banish number and measurement from geometry (BALL, PDF p. 52). If we measure a length by counting how many times the unit goes into it, the diagonal of a square cannot be measured with its side as the unit. Theodorus of Cyrene is said to have proved geometrically that lengths whose square is a number from 3 to 17 that is not the square of a whole number have no common measure with the unit (BALL, PDF p. 58). Eudoxus gave the Greeks a doctrine of proportion that also applies to quantities without a common measure (CAJORI, PDF p. 47). This is our question: a length has a common measure with the unit exactly when it is a fraction of the unit, and that the length whose square is 3 is not a fraction we shall show in lemma 1.27.

Lemma 1.27 No rational number has square 3 (noben ulomek nima kvadrata 3)

There are no integers \(p\) and \(q \neq 0\) for which \((p/q)^2 = 3\).

Proof

We prove this by contradiction: we assume that such a fraction exists and derive something that cannot hold.

  1. Suppose that \((p/q)^2 = 3\) for integers \(p\) and \(q \neq 0\). We may take \(q > 0\): if \(q < 0\), we write the fraction with \(-p\) and \(-q\), since \((-p)/(-q) = p/q\).
  2. Among all such ways of writing it with a positive denominator we choose the one with the smallest denominator \(q\). It exists, because every nonempty set of natural numbers has a smallest element.
  3. We multiply the equation \((p/q)^2 = 3\) by \(q^2\) and get \(p^2 = 3q^2\). So the number \(p^2\) is divisible by \(3\).
  4. On division by \(3\) every integer gives the remainder \(0\), \(1\) or \(2\), so \(p = 3k\), \(p = 3k + 1\) or \(p = 3k + 2\) for some integer \(k\). In the second and the third case we expand the square:
    \[\begin{aligned} (3k + 1)^2 &= 9k^2 + 6k + 1 = 3\,(3k^2 + 2k) + 1 , \\ (3k + 2)^2 &= 9k^2 + 12k + 4 = 3\,(3k^2 + 4k + 1) + 1 . \end{aligned}\]
    In both cases \(p^2\) gives the remainder \(1\) on division by \(3\) and is not divisible by \(3\), which contradicts step 3. What remains is \(p = 3k\).
  5. We put \(p = 3k\) into \(p^2 = 3q^2\): \(9k^2 = 3q^2\), and after dividing by \(3\), \(q^2 = 3k^2\). So the number \(q^2\) is divisible by \(3\), and by the reasoning of step 4, \(q = 3m\) for some integer \(m\). Since \(q > 0\), we have \(m > 0\) and \(m < q\).
  6. Then \(p/q = 3k/(3m) = k/m\), so \((k/m)^2 = 3\), and the denominator \(m\) is positive and smaller than \(q\). This contradicts the choice in step 2, where \(q\) was the smallest. So the assumption of step 1 is false.

Source: LEBL1 Example 1.1.4 (PDF pp. 24-25) gives the same proof for the square \(2\), with even and odd numbers in place of the remainders on division by \(3\). For the square \(3\) the proof is not from the source.

So there is no fraction with the square \(\tfrac13\), and if we knew only the fractions, the point \(\xi\) would not exist. At the fractions \(t\) with \(3t^2 < 1\) the tangent would be less steep than the line through the end points, at those with \(3t^2 > 1\) steeper, and there is no fraction with \(3t^2 = 1\). Among the fractions there would be no equally steep tangent anywhere. The statement we need would not hold among the fractions.

Where is the hole? Let us draw the nonnegative fractions on the number line (figure 1.51). Those with the square below \(3\), such as \(1\), \(1{,}7\) and \(1{,}73\), we draw grey, and those with the square above \(3\), such as \(1{,}74\) and \(2\), blue. Every nonnegative fraction gets a colour, because by lemma 1.27 no rational number has square 3. Every grey fraction lies to the left of every blue one. Why? For this we need a simple fact about squares.

Lemma 1.28 A larger nonnegative number has a larger square (večje nenegativno število ima večji kvadrat)

For nonnegative numbers \(s\) and \(t\), \(s < t\) holds exactly when \(s^2 < t^2\), and \(s \le t\) exactly when \(s^2 \le t^2\).

Proof

We must show that \(s < t\) implies \(s^2 < t^2\) and the other way round, and the same for \(\le\).

  1. Let \(0 \le s < t\). We write the difference of the squares as a product: \(t^2 - s^2 = (t - s)(t + s)\).
  2. The factor \(t - s\) is positive, because \(s < t\). The factor \(t + s\) is positive, because \(t > s \ge 0\), so \(t > 0\), and \(s \ge 0\). A product of positive numbers is positive, so \(t^2 - s^2 > 0\) and \(s^2 < t^2\).
  3. Conversely, let \(s^2 < t^2\). If \(t \le s\), then either \(t = s\), and then \(t^2 = s^2\), or \(t < s\), and then by steps 1 and 2 with the roles swapped \(t^2 < s^2\). Both contradict \(s^2 < t^2\). So \(s < t\).
  4. The inequality \(s \le t\) holds exactly when \(t < s\) does not hold. By steps 1 to 3 with the roles swapped, \(t < s\) holds exactly when \(t^2 < s^2\) holds, and this holds exactly when \(s^2 \le t^2\) does not hold. So \(s \le t\) exactly when \(s^2 \le t^2\).

Source: LEBL1 Example 1.2.3 (PDF p. 30) uses the first implication for the uniqueness of the root. The proof is not from the source.

For a grey fraction \(s\) and a blue fraction \(t\) we have \(s^2 < 3 < t^2\), so by lemma 1.28 that a larger nonnegative number has a larger square, \(s < t\). The grey and the blue fractions come close to the same bound from both sides: \(1{,}732^2 = 2{,}999824\) is below \(3\) and \(1{,}733^2 = 3{,}003289\) above \(3\), and even more tightly \(1{,}73205^2 = 2{,}9999972\dots\) is below \(3\) and \(1{,}73206^2 = 3{,}0000318\dots\) above \(3\). By the same lemma a number with the square \(3\) would lie to the right of all the grey fractions and to the left of all the blue ones, that is, at the bound between them. Among the fractions there is none. That is where the hole is.

It was not satisfactory to calculate with numbers that are not fractions as if they were fractions. The question of what these numbers actually are demanded greater rigour in the nineteenth century (CAJORI, PDF p. 412). In his textbook Cours d'analyse, which we mentioned in section 1.3.3, Cauchy wrote that such a number is a number approached by fractions with better and better approximations (CAJORI, PDF p. 412). But if we know only fractions, such a number does not exist when it is not a fraction, so the description is circular (CAJORI, PDF p. 412). It is the same for us: the grey fractions approach a bound, but at the bound there is nothing among the fractions to be approached. So people wanted to define such numbers without approaching. Four men achieved this independently and almost at the same time (CAJORI, PDF p. 412-413). Charles Méray published first, in 1869, Weierstrass's presentation was first printed in 1872, and in 1872 Richard Dedekind and Georg Cantor also published (CAJORI, PDF p. 413). Dedekind's treatise is called Stetigkeit und irrationale Zahlen (Continuity and Irrational Numbers). In it he declared every cut in the set of fractions to be a number, and the open cuts are new numbers that are not fractions (CAJORI, PDF p. 413). A cut (rez) is a division of all fractions into a left and a right group such that every fraction of the left group is smaller than every fraction of the right group. It is open if the left group has no largest fraction and the right group no smallest one. Such are our grey and blue fractions if we add to the grey ones also zero and all the negative fractions.

The rules of arithmetic do not notice this hole, because they also hold for fractions. If we want to say that the real numbers have no holes, we must require it separately. Before that, though, we must describe the hole, and without the number that is missing, since there is no such number among the fractions. We describe it by the bound up to which the grey fractions reach.

1.8.2 Upper bound and supremum

The grey fractions do not reach past the number \(2\): each of them is smaller than it, because \(2\) has the square \(4 > 3\). Nor do they reach past \(1{,}74\) or past any blue fraction. The numbers that a set does not reach past get a name.

Definition 1.29 Upper bound and bounded set (zgornja meja in omejena množica)

Let \(A \subseteq \mathbb R\) be a set of real numbers. A number \(b\) is an upper bound (zgornja meja) of the set \(A\) if \(x \le b\) for every \(x \in A\), and a lower bound (spodnja meja) if \(x \ge b\) for every \(x \in A\). A set is bounded above (navzgor omejena) if it has some upper bound, bounded below (navzdol omejena) if it has some lower bound, and bounded (omejena) if it is both.

Source: LEBL1 Def. 1.1.2 (PDF pp. 23-24).

So an upper bound is a number, while being bounded is a property of a set. There is not just one upper bound. For \(A = \{1, 2, 3\}\) the numbers \(3\), \(3{,}5\) and \(100\) are upper bounds, because no element is larger than them. The number \(2{,}5\), though, is not an upper bound, because the element \(3\) is larger than it. Every number \(c\) larger than an upper bound \(b\) is again an upper bound: for every element \(x\), from \(x \le b < c\) it follows that \(x < c\). An upper bound also need not be an element of the set: \(2\) is an upper bound of the grey fractions, but it is not grey itself. The set of all real numbers \(\mathbb R\) is not bounded above: for every number \(b\), \(b + 1\) is a real number larger than \(b\), so \(b\) is not an upper bound.

Among the upper bounds of the grey fractions, \(2\) tells less precisely how far they reach than \(1{,}74\), and this one in turn less precisely than \(1{,}733\). The closer an upper bound comes to the set, the better it describes it. The hole would be filled by the least upper bound: a number that no grey fraction exceeds, while every smaller number is exceeded by some grey fraction.

Definition 1.30 Supremum and infimum (supremum in infimum)

Let \(A \subseteq \mathbb R\). The supremum (supremum) of the set \(A\), written \(\sup A\), is a number \(s\) that is an upper bound of the set \(A\) and is not larger than any of its upper bounds: \(x \le s\) for every \(x \in A\) and \(s \le b\) for every upper bound \(b\) of the set \(A\). The infimum (infimum) \(\inf A\) is a lower bound \(i\) of the set \(A\) that is not smaller than any of its lower bounds. If the supremum lies in the set, \(\sup A \in A\), we call it the maximum (maksimum) of the set, \(\max A\), and if the infimum lies in it, the minimum (minimum), \(\min A\).

Source: LEBL1 Def. 1.1.2 (PDF pp. 23-24), maximum and minimum §1.2.4 (PDF p. 34).

So the supremum is the least upper bound, and the infimum the greatest lower bound. Both names are Latin: supremum means "the highest", infimum "the lowest". The maximum is the largest element of a set, the minimum the smallest. The definition of the supremum has two parts with different tasks. The first requires that no element of the set lies above \(s\). The second requires that \(s\) is the smallest among the upper bounds. So a number below \(s\) is no longer an upper bound, and some element of the set exceeds it.

We defined upper bounds and the supremum for sets of real numbers. They are defined in the same way in every ordered set (urejena množica), that is, a set in which for any two elements \(x\) and \(y\) exactly one of \(x < y\), \(x = y\) and \(y < x\) holds, and \(x < y\) and \(y < z\) imply \(x < z\) (LEBL1 Def. 1.1.1 and 1.1.2, PDF pp. 23-24). The fractions on their own are such a set too. An upper bound of a set of fractions among the fractions is a fraction that the set does not go beyond, and its supremum among the fractions is the smallest such fraction, if there is one. We will need such a supremum at the end of section 1.8.6.

Let us try the definition on the set \(A = \{x \in \mathbb R : 0 \le x < 1\}\) (figure 1.52). The number \(1\) is an upper bound, because every element is smaller than \(1\). Is \(0{,}9\) an upper bound? It is not, because \(0{,}95\) is an element of the set and larger than \(0{,}9\). It is the same with every number \(b\) with \(0 \le b < 1\): the midpoint \(c = \tfrac12(b + 1)\) is larger than \(b\), since \(c - b = \tfrac12(1 - b) > 0\), and it is an element of the set \(A\), since \(c > b \ge 0\) and \(1 - c = \tfrac12(1 - b) > 0\). Numbers below \(0\) are not upper bounds at all, because \(0 \in A\). So every upper bound is at least \(1\), and \(\sup A = 1\). But the number \(1\) is not an element of the set, so \(A\) has no maximum: for every element \(x\), \(\tfrac12(x + 1)\) is a larger element, by the same computation with \(x\) in place of \(b\). The set has no largest element, but it has a supremum. This is exactly the concept we were looking for: a bound that the set comes arbitrarily close to without reaching it. The infimum of this set is \(0\): the number \(0\) is a lower bound, because every element is at least \(0\), and it is an element of the set, so no lower bound is larger than it. So it is the minimum of the set.

The notation \(\sup A\) claims that the supremum is a single number. Let us check.

Lemma 1.31 Uniqueness of the supremum (enoličnost supremuma)

A set of real numbers has at most one supremum and at most one infimum.

Proof

We must show that two suprema of the same set are equal, and the same for the infimum.

  1. Let \(s\) and \(s'\) be suprema of the set \(A\).
  2. The number \(s'\) is an upper bound of the set \(A\), and \(s\) is not larger than any upper bound. So \(s \le s'\).
  3. With the roles of the numbers \(s\) and \(s'\) swapped we get \(s' \le s\).
  4. From \(s \le s'\) and \(s' \le s\) it follows that \(s = s'\).
  5. Let \(i\) and \(i'\) be infima of the set \(A\). The number \(i'\) is a lower bound, and \(i\) is not smaller than any lower bound, so \(i \ge i'\).
  6. With the roles swapped we get \(i' \ge i\), and from the two inequalities it follows that \(i = i'\).

Source: LEBL1, the paragraph after Def. 1.1.2 (PDF p. 24).

The proof showed a general way of showing that two numbers are equal: we prove \(a \le b\) and \(b \le a\).

1.8.3 Completeness axiom

Now we can describe the hole among the fractions without the number that is missing. The grey fractions form a nonempty set that is bounded above, for example by the number \(2\). Its supremum would have to stand at the place of the hole. At the end of this section we will see that this supremum would have to have the square \(3\), so it is not among the fractions. We want the real numbers to have no such holes. The rules of arithmetic do not contain this requirement, because they also hold for fractions, so we accept it as an axiom, that is, as a statement that we do not prove.

Definition 1.32 Completeness axiom (aksiom polnosti)

Every nonempty set of real numbers that is bounded above, that is, a set with at least one element and with an upper bound, has a supremum.

Source: LEBL1 Def. 1.1.3 (PDF p. 24) and Thm 1.2.1 (PDF p. 29). LEBL1 calls the property the least-upper-bound property (lastnost najmanjše zgornje meje).

The completeness axiom is a statement about the set of real numbers as a whole, not about a single number. The name says that the number line is complete, without holes. The requirement is also called Dedekind completeness, after Dedekind, who described the holes among the fractions by cuts (LEBL1, PDF p. 24). Together with the rules of arithmetic and the properties of the integers from section 1.8.1, this is all we assume about numbers. The rules of arithmetic also hold for fractions, but the completeness axiom does not, so it is exactly what tells the real numbers apart from the fractions. That numbers with all these properties exist at all is a theorem, which mathematicians prove by building the real numbers from the fractions. The construction goes beyond this book (LEBL1 Thm 1.2.1, PDF p. 29, refers to other books for it).

Why does the axiom require both conditions? A set that is not bounded above, for example \(\mathbb R\), has no upper bound at all, so it has no least one either. The empty set, which has no element, has too many upper bounds, on the other hand. Since it has no elements, no element is larger than the number \(b\), so every real number is its upper bound. But there is no smallest real number, since \(b - 1\) is smaller than \(b\). Without either condition the axiom would require something that no numbers satisfy.

1.8.4 Properties of the supremum

The axiom speaks only about the supremum of sets that are bounded above. Let us derive from it two tools that we will need all the time.

The first is the infimum. Do we need a new axiom for it? No. If we change the sign of all the elements, the inequalities turn around. The lower bounds of the set \(A\) become upper bounds of the set \(-A = \{-x : x \in A\}\), and the greatest lower bound becomes the least upper bound, which exists by the axiom. For \(A = \{1, 2, 3\}\) we have \(-A = \{-3, -2, -1\}\), \(\sup(-A) = -1\) and \(\inf A = 1 = -\sup(-A)\).

The second makes use of the word least. A number just below the supremum, for example \(\sup A - 0{,}001\), is no longer an upper bound, so some element of the set exceeds it. So the elements of the set come arbitrarily close to the supremum (figure 1.53). For \(A = \{x \in \mathbb R : 0 \le x < 1\}\) and the error \(0{,}001\) such an element is \(0{,}9995\).

Theorem 1.33 Properties of the supremum and infimum (lastnosti supremuma in infimuma)

Let \(A \subseteq \mathbb R\) be a nonempty set.

  1. If \(A\) is bounded below, it has an infimum, and \(\inf A = -\sup(-A)\), where \(-A = \{-x : x \in A\}\).
  2. If \(A\) is bounded above, then for every \(\eta > 0\) there is an \(x \in A\) with \(\sup A - \eta < x \le \sup A\). If \(A\) is bounded below, then for every \(\eta > 0\) there is an \(x \in A\) with \(\inf A \le x < \inf A + \eta\).
Proof

We must show both statements of the theorem.

1. Existence of the infimum.

  1. The set \(A\) is bounded below, so it has a lower bound \(b\): \(x \ge b\) for every \(x \in A\).
  2. We multiply the inequality \(x \ge b\) by \(-1\), which turns it around: \(-x \le -b\). The elements of the set \(-A\) are exactly the numbers \(-x\) with \(x \in A\), so \(-b\) is an upper bound of the set \(-A\).
  3. The set \(-A\) is nonempty, because \(A\) is nonempty. So by the completeness axiom 1.32 it has a supremum \(c = \sup(-A)\).
  4. Let \(x \in A\). Then \(-x \in -A\), and since \(c\) is an upper bound of the set \(-A\), we have \(-x \le c\). We multiply by \(-1\): \(x \ge -c\). This holds for every \(x \in A\), so \(-c\) is a lower bound of the set \(A\).
  5. Let \(b\) be any lower bound of the set \(A\). By step 2, \(-b\) is an upper bound of the set \(-A\), and since \(c\) is not larger than any upper bound, \(c \le -b\). We multiply by \(-1\): \(b \le -c\).
  6. The lower bound \(-c\) (step 4) is thus not smaller than any lower bound (step 5), so it is the infimum: \(\inf A = -c = -\sup(-A)\).

2. Approaching the supremum.

  1. Let \(A\) be bounded above and \(\eta > 0\). By the completeness axiom 1.32 the supremum \(\sup A\) exists.
  2. Since \(\eta > 0\), we have \(\sup A - \eta < \sup A\).
  3. So the number \(\sup A - \eta\) is not an upper bound of the set \(A\). If it were, then by the definition of the supremum 1.30 the supremum would not be larger than it, which contradicts step 2.
  4. That \(\sup A - \eta\) is not an upper bound means that it is not true that \(x \le \sup A - \eta\) for every \(x \in A\). So there is an \(x \in A\) with \(x > \sup A - \eta\).
  5. For the same \(x\) we have \(x \le \sup A\), because the supremum is an upper bound.
  6. For a set that is bounded below we use item 1. The set \(-A\) is bounded above (step 2 of item 1), so by steps 1 to 5 there is an element \(-x \in -A\) with \(\sup(-A) - \eta < -x\). We multiply the inequality by \(-1\), which turns it around: \(x < -\sup(-A) + \eta = \inf A + \eta\). The number \(x\) is an element of the set \(A\), and \(x \ge \inf A\), because the infimum is a lower bound.

Source: LEBL1 Prop. 1.1.11 and 1.2.8 (PDF pp. 27 and 33). The source leaves the proof of Prop. 1.2.8 to the reader.

Item 2 is the tool we will use most often: the elements of the set are arbitrarily close to the supremum.

We will need one more tool, which does not come from the completeness axiom but only from the rules of arithmetic. It tells how we prove inequalities. If a number \(x\) is not larger than any positive number, it cannot be positive: a positive \(x\) would be larger than its half \(x/2\), which is also positive. We used a similar argument in step 8 of the proof of lemma 1.7 on the uniqueness of the limit. There the inequality was strict and it was enough to compare the number with itself, here it is not strict, so we take half.

Lemma 1.34 An inequality tested with all positive numbers (neenakost z vsemi pozitivnimi števili)

If a real number \(x\) satisfies \(x \le \eta\) for every \(\eta > 0\), then \(x \le 0\). If in addition \(x \ge 0\), then \(x = 0\).

Proof

We must show that \(x\) is not positive, and that it equals zero when \(x \ge 0\).

  1. Let \(x \le \eta\) hold for every \(\eta > 0\). We argue by contradiction: suppose that \(x > 0\).
  2. We choose \(\eta = x/2\). This number is positive, because \(x > 0\).
  3. We have \(x - \eta = x - x/2 = x/2 > 0\), so \(x > \eta\). This contradicts the assumption \(x \le \eta\) for this \(\eta\). So \(x > 0\) does not hold, and \(x \le 0\).
  4. If in addition \(x \ge 0\), then from \(x \le 0\) and \(x \ge 0\) it follows that \(x = 0\).

Source: LEBL1 Prop. 1.2.2 (PDF p. 29).

The lemma turns an inequality into a test with all positive numbers: we prove the inequality \(x \le 0\) by showing \(x \le \eta\) for every \(\eta > 0\). In the same way we prove that two numbers are equal. If the distance \(|x - y|\) between them is at most \(\eta\) for every \(\eta > 0\), then by lemma 1.34 on an inequality tested with all positive numbers \(|x - y| = 0\), and \(x = y\).

1.8.5 Archimedean property

In proofs with limits we require that some quantity is smaller than every allowed error \(\eta > 0\), for example than \(0{,}01\) or than \(0{,}000001\). For this we will need that every positive number, however small, is larger than some fraction \(1/n\). For \(\eta = 0{,}000001\) the number \(n = 1\,000\,001\) will do, but at \(n = 1\,000\,000\) the fraction \(1/n\) would be equal to \(\eta\), not smaller. Does such an \(n\) exist for every \(\eta\)? The inequality \(1/n < \eta\) holds exactly when \(n > 1/\eta\), so this is the same question as whether the natural numbers grow past every bound, or whether there might be a real number that is larger than all natural numbers. Intuition says there is not. But about the real numbers we have assumed only the rules of arithmetic and the completeness axiom, so the answer must come from them.

The Greeks avoided quantities smaller than every given quantity but not zero in rigorous proofs. The great geometers of that time resorted to an extreme measure: they excluded such infinitely small quantities from proofs by a postulate, that is, by a requirement that they do not prove. This was done by Eudoxus, Euclid and Archimedes (CAJORI, PDF p. 51). In the preface to the Quadrature of the Parabola Archimedes stated a requirement that he attributed to Eudoxus: when two quantities are unequal, the difference can be added to itself so often that every finite quantity is exceeded (CAJORI, PDF p. 51). Euclid wrote it in Elements V, 4 as a definition of ratio: two magnitudes have a ratio when the lesser can be multiplied so as to exceed the other (CAJORI, PDF p. 51). The same requirement is Axiom V of Archimedes' On the Sphere and Cylinder of 225 BC (LEBL1, PDF p. 31). The Greeks may nevertheless have used infinitely small quantities in the search for truths. Archimedes' book The Method, discovered in 1906, shows that he regarded them as scientific enough to hint to him what the theorems state, but not firm enough to prove with them (CAJORI, PDF p. 51). Mathematicians took no interest in the requirement that every quantity is exceeded until the real numbers were built from the fractions. Otto Stolz showed that it follows from Dedekind's requirement on cuts of fractions (CAJORI, PDF p. 51). We shall do the same: we shall derive the requirement from the completeness axiom.

The proof is by contradiction. If the natural numbers were bounded above, they would have a supremum \(b\) by the completeness axiom. The number \(b - 1\) is smaller than the least upper bound, so some natural number \(m\) exceeds it. But then \(m + 1\) is a natural number above \(b\), and \(b\) is not an upper bound at all.

Theorem 1.35 Archimedean property (Arhimedova lastnost)

The set of natural numbers \(\mathbb N\) is not bounded above. So for real numbers \(x > 0\) and \(y\) there is a natural number \(n\) with \(n\,x > y\), and for every \(\eta > 0\) there is a natural number \(N\) such that \(1/n < \eta\) for every natural number \(n \ge N\).

Proof

We must show that \(\mathbb N\) is not bounded above, and derive the other two statements from this.

The set \(\mathbb N\) is not bounded above.

  1. We argue by contradiction. Suppose that \(\mathbb N\) is bounded above.
  2. The set \(\mathbb N\) is nonempty, because it contains \(1\). So by the completeness axiom 1.32 it has a supremum \(b = \sup \mathbb N\).
  3. By theorem 1.33 on the properties of the supremum and infimum, item 2, with \(\eta = 1\) there is a natural number \(m\) with \(m > b - 1\).
  4. We add \(1\) to the inequality and get \(m + 1 > b\). The number \(m + 1\) is natural.
  5. So the natural number \(m + 1\) is larger than \(b\), and \(b\) is not an upper bound of the set \(\mathbb N\). This contradicts step 2, where \(b\) is the supremum and so an upper bound. The assumption of step 1 is false.

A multiple exceeds every number.

  1. Let \(x > 0\) and \(y\) be real numbers. Since \(x \neq 0\), the number \(y/x\) exists.
  2. By the first part, \(y/x\) is not an upper bound of the set \(\mathbb N\), so there is an \(n \in \mathbb N\) with \(n > y/x\).
  3. We multiply the inequality by the positive number \(x\), which does not turn it around: \(n\,x > y\).

The fractions \(1/n\) are smaller than \(\eta\) from some point on.

  1. Let \(\eta > 0\). We use the previous part with \(x = \eta\) and \(y = 1\): there is a natural number \(N\) with \(N\eta > 1\).
  2. We multiply the inequality by the positive number \(1/N\) and get \(\eta > 1/N\).
  3. Let \(n \ge N\). Then \(1/n \le 1/N\), because for positive numbers a larger denominator gives a smaller fraction: \(1/N - 1/n = (n - N)/(nN) \ge 0\).
  4. From \(1/n \le 1/N\) and \(1/N < \eta\) it follows that \(1/n < \eta\), for every \(n \ge N\).

Source: LEBL1 Thm 1.2.4 (i) and Cor. 1.2.5 (PDF pp. 31-32).

The theorem says that among the real numbers there is no number larger than all natural numbers, and no positive number smaller than all fractions \(1/n\). The second statement reads: however small the steps of length \(x > 0\) we take, with enough steps we pass every number \(y\) (figure 1.54). The third says that every positive number is larger than \(1/n\) when \(n\) is large enough, and not just for one \(n\), but for every one from some \(N\) on.

Now we can find the infimum of the set \(\{1/n : n \in \mathbb N\}\). The number \(0\) is a lower bound, because \(1/n > 0\) for every \(n\). But no number \(b > 0\) is a lower bound, because by the theorem there is an \(n\) with \(1/n < b\). For \(b = 0{,}001\) this is, for example, \(n = 1001\). So every lower bound is at most \(0\), and \(\inf\{1/n : n \in \mathbb N\} = 0\) (LEBL1 Cor. 1.2.5, PDF p. 32). The infimum is not an element of the set, because \(1/n \neq 0\), so the set has no minimum. It was the same with the set \(\{x : 0 \le x < 1\}\) and its supremum: the set comes arbitrarily close to its bound without reaching it.

1.8.6 Square root

Now we can fill the hole with which this section began, and for every nonnegative number \(x\), not only for \(3\). At the same time we fill a gap that the book has carried since section 1.5.4: there we computed the length of a vector with a square root, without knowing that the root exists.

As the candidate for \(\sqrt x\) we take the bound up to which the nonnegative numbers with the square below \(x\) reach, that is, the supremum \(r\) of the set \(A = \{t \in \mathbb R : t \ge 0,\ t^2 < x\}\) (figure 1.55). For \(x > 0\) the set \(A\) is nonempty, because it contains \(0\), and bounded above, as we show in the proof, so by the completeness axiom it has a supremum. We treat the case \(x = 0\) separately. It remains to show \(r^2 = x\), and we do this by ruling out the other two possibilities. If the square were too small, \(r^2 < x\), we could increase \(r\) by a small \(h > 0\), and \(r + h\) would still be in \(A\). Then \(r\) would not be an upper bound. If the square were too large, \(r^2 > x\), we could decrease \(r\) by a small \(h > 0\), and \(r - h\) would still be an upper bound. Then \(r\) would not be the least upper bound. All the work lies in finding a small enough \(h\).

Let us try with numbers for \(x = 3\). Can \(r = 1{,}73\) be the supremum? Its square \(2{,}9929\) is below \(3\). The number \(1{,}732\) has the square \(2{,}999824\), still below \(3\), so it is an element of the set \(A\) and larger than \(1{,}73\). So the number \(1{,}73\) is not even an upper bound. Can \(r = 1{,}74\) be the supremum? Its square \(3{,}0276\) is above \(3\). The number \(1{,}733\) has the square \(3{,}003289\), still above \(3\), so by lemma 1.28 that a larger nonnegative number has a larger square, every element of the set \(A\) is smaller than it. So the number \(1{,}733\) is an upper bound smaller than \(1{,}74\), and \(1{,}74\) is not the least upper bound. The proof does the same with a general \(h\), chosen so that it works for every square that is too small or too large.

Theorem 1.36 Existence of square roots (obstoj kvadratnega korena)

For every real number \(x \ge 0\) there is exactly one number \(r \ge 0\) with \(r^2 = x\). This number is the square root (kvadratni koren) \(\sqrt x\).

Proof

We must show that such a number \(r\) exists and that there is only one.

Uniqueness.

  1. Let \(r \ge 0\) and \(s \ge 0\) be numbers with \(r^2 = s^2 = x\). Then \(0 = r^2 - s^2 = (r - s)(r + s)\).
  2. A product is zero only if one of the factors is zero. If \(r - s = 0\), then \(r = s\). If \(r + s = 0\), the nonnegative numbers \(r\) and \(s\) are both zero, since otherwise the sum would be positive, and again \(r = s\).

The case \(x = 0\).

  1. For \(x = 0\) the number is \(r = 0\), because \(0 \ge 0\) and \(0^2 = 0\).

A candidate for the root.

  1. Let \(x > 0\) and \(A = \{t \in \mathbb R : t \ge 0,\ t^2 < x\}\).
  2. The set \(A\) is nonempty, because it contains \(0\): we have \(0 \ge 0\) and \(0^2 = 0 < x\).
  3. The number \(1 + x\) is an upper bound of the set \(A\). For \(t \ge 1 + x\), by lemma 1.28 that a larger nonnegative number has a larger square, \(t^2 \ge (1 + x)^2\). Since \((1 + x)^2 - x = 1 + x + x^2 > 0\), we have \(t^2 > x\). Such a \(t\) is not in \(A\), so every element of the set \(A\) is smaller than \(1 + x\). Why do we not simply take \(x\)? Because for \(x < 1\) it is not an upper bound: for \(x = 0{,}25\) we have \(0{,}4 \in A\), since \(0{,}4^2 = 0{,}16 < 0{,}25\), and \(0{,}4 > 0{,}25\).
  4. By the completeness axiom 1.32 there is \(r = \sup A\). We have \(r \ge 0\), because \(0 \in A\) and \(r\) is an upper bound. We will show \(r^2 = x\) by ruling out the possibilities \(r^2 < x\) and \(r^2 > x\).

The square is not smaller than \(x\).

  1. Suppose, on the contrary, that \(r^2 < x\). We will find an \(h > 0\) for which still \((r + h)^2 < x\).
  2. We expand the square of the sum and take out \(h\): \((r + h)^2 - r^2 = 2rh + h^2 = h\,(2r + h)\).
  3. For \(0 < h < 1\) we have \(2r + h < 2r + 1\), and multiplying by the positive \(h\) we get \(h\,(2r + h) < h\,(2r + 1)\).
  4. By steps 2 and 3 it is enough to find an \(h\) with \(0 < h < 1\) and \(h\,(2r + 1) < x - r^2\).
  5. The numbers \(1\) and \((x - r^2)/(2r + 1)\) are positive, because \(x - r^2 > 0\) and \(2r + 1 > 0\). For \(h\) we take half of the smaller of them. Half, so that both inequalities of step 4 are strict.
  6. The number \(h\) is positive, because it is half of a positive number, and it is smaller than that number, which is larger neither than \(1\) nor than \((x - r^2)/(2r + 1)\). So \(0 < h < 1\) and \(h < (x - r^2)/(2r + 1)\). Multiplying by the positive \(2r + 1\) we get \(h\,(2r + 1) < x - r^2\).
  7. By steps 2, 3 and 6,
    \[(r + h)^2 - r^2 = h\,(2r + h) < h\,(2r + 1) < x - r^2 ,\]
    and adding \(r^2\) gives \((r + h)^2 < x\). Since also \(r + h \ge 0\), we have \(r + h \in A\).
  8. Since \(h > 0\), we have \(r + h > r\). So the element \(r + h\) of the set \(A\) is larger than \(r\), which contradicts \(r\) being an upper bound. So \(r^2 < x\) does not hold.

The square is not larger than \(x\).

  1. Suppose, on the contrary, that \(r^2 > x\). We will find an \(h > 0\) for which \(r - h\) is still an upper bound of the set \(A\).
  2. We have \(r \neq 0\), because \(r^2 > x > 0\). Since also \(r \ge 0\), we have \(r > 0\).
  3. Let \(h = (r^2 - x)/(2r)\). It is chosen so that \(2rh = r^2 - x\). We have \(h > 0\), because the numerator and the denominator are positive, and \(h < r/2 < r\), because \(r^2 - x < r^2\). So \(r - h > 0\).
  4. We expand the square of the difference and use \(2rh = r^2 - x\):
    \[(r - h)^2 = r^2 - 2rh + h^2 = x + h^2 > x ,\]
    because \(h^2 > 0\).
  5. Let \(t \in A\). If \(t \ge r - h\), then by lemma 1.28 that a larger nonnegative number has a larger square, \(t^2 \ge (r - h)^2 > x\). This contradicts the condition \(t^2 < x\). So \(t < r - h\).
  6. This holds for every \(t \in A\), so \(r - h\) is an upper bound of the set \(A\). Since \(h > 0\), we have \(r - h < r\), but the supremum \(r\) is not larger than any upper bound. This is impossible, so \(r^2 > x\) does not hold.

Conclusion.

  1. Of the three possibilities \(r^2 < x\), \(r^2 = x\) and \(r^2 > x\), what remains is \(r^2 = x\). So the number \(r \ge 0\) is the root we were looking for.

Source: LEBL1 Example 1.2.3 (PDF pp. 29-30) for \(x = 2\), with the same conditions on the first \(h\) and the same second \(h\). Taking half of the smaller number, the general \(x\) and the upper bound \(1 + x\) are not from the source. The source leaves the general \(x\) to the reader (PDF p. 30).

The proof showed how we test a candidate for the supremum: if we can move it up a little and it stays in the set, or down a little and it stays an upper bound, it is not the supremum. For the square that was too small we chose a small enough \(h\) as half of the smaller of two numbers, each of which takes care of one requirement. This move will come back in almost every proof that follows.

For fractions the theorem does not hold, and the proof says why. If \(x\) and \(r\) are fractions, both numbers \(h\) that the proof chooses are fractions too. Suppose the set of grey fractions \(\{t \in \mathbb Q : t \ge 0,\ t^2 < 3\}\) had a least upper bound \(r\) among the fractions. The same steps would rule out \(r^2 < 3\) and \(r^2 > 3\), because \(r + h\) and \(r - h\) would again be fractions. What remains is \(r^2 = 3\), but by lemma 1.27 no rational number has square 3. So the set of grey fractions has no supremum among the fractions, and the completeness axiom does not hold for the fractions (LEBL1 Example 1.1.4, PDF pp. 24-25, shows this for the square \(2\)). This is the precise form of the hole we saw in figure 1.51.

Among the real numbers, however, there is no hole: \(\sqrt 3\) exists, and with it the point \(\xi = 1/\sqrt 3\), where the tangent to the graph of the function \(t^3\) has the slope \(1\). All the lengths of vectors from section 1.5.4 exist too. But that such a point in between exists for every function with a derivative we will prove only in the next sections. For this we need endless strings of numbers that approach some number. We continue with them.
