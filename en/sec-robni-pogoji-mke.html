Chapter 7 Basics of FEM for bars and trusses

7.3 Boundary conditions, solution and reactions (robni pogoji, rešitev in reakcije)

In section 7.2.3 we assembled the matrix and the right-hand side of the hanging bar of chapter 6. The bar is made of steel, \(L = 10\) m long, with diameter 10 mm, axial stiffness \(EA = 1{,}539 \cdot 10^7\) N and self weight \(q = \rho g A = 6{,}010\) N/m. The axis \(x\) points down. We divide it into two elements of length \(h = 5\) m, with nodes \(0\), \(1\) and \(2\) at \(x = 0\), \(5\) and \(10\) m. The unknowns are the node displacements \(d_0\), \(d_1\), \(d_2\) along the axis, and the right-hand side consists of consistent nodal forces (definition 7.7), which for an element with constant load is half the weight of the element at each of its nodes. The system of the whole structure is

\[\frac{EA}{h} \begin{pmatrix} 1 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 1 \end{pmatrix} \begin{pmatrix} d_0 \\ d_1 \\ d_2 \end{pmatrix} = \begin{pmatrix} 15{,}02 \\ 30{,}05 \\ 15{,}02 \end{pmatrix}\ \text{N} , \tag{7.13}\]

where \(EA/h = 3{,}079 \cdot 10^6\) N/m. In chapter 6 we left out node \(0\) because the bar is fixed there. Here three questions arise. Why does the matrix of equation (7.13) have no inverse, and what is missing from it? How do we add supports, including those that move an end by a given distance? And how do we obtain the forces with which the supports hold the structure, which the system with the omitted row does not contain?

7.3.1 Mathematics: the singular stiffness matrix (matematika: singularna togostna matrika)

In section 7.2.3 we saw that the matrix of equation (7.13) multiplies the column \((1, 1, 1)\) into the zero column, because the sum of every row is zero. The meaning is plain: if all three nodes move by the same distance \(c\), the bar moves as a whole and no element stretches (figure 7.6). Such a displacement needs no force, and the strain energy is zero.

What does this mean for the system \(\mat K\,\vek d = \vek f\)? The sum of the three rows gives zero on the left for all \(d_0\), \(d_1\), \(d_2\) and the weight of the bar \(60{,}097\) N on the right, so the system has no solution (section 7.2.3). Let the bar be fixed at \(x = 0\) and let the support force be \(-60{,}097\) N (upward, because the axis points down), which we compute in section 7.3.4. Then the right-hand side is \((15{,}024 - 60{,}097,\ 30{,}049,\ 15{,}024) = (-45{,}073,\ 30{,}049,\ 15{,}024)\) N with sum zero. This system has a solution, one is \(\vek d^* = (0,\ 14{,}64,\ 19{,}52)\) µm, as we will see in section 7.3.2, and if \(\vek d^*\) is one of them, then \(\vek d^* + c\,(1, 1, 1)\) is a solution for every number \(c\), because \(\mat K\,(\vek d^* + c\,\vek 1) = \mat K\,\vek d^* + c\,\mat K\,\vek 1 = \mat K\,\vek d^*\). A system whose matrix has a nonzero column with product zero therefore has either no solution or infinitely many. What is missing is a support that holds the bar and thereby decides how large \(c\) is.

We want to say the same for every structure and not only for this example. The energy is \(\tfrac12\,\vek d^\T\mat K\,\vek d\) and is never negative, but it can be zero also for a nonzero \(\vek d\). We give matrices with this property a name. The name is similar to a positive definite matrix (definition 6.27), except that the value zero is allowed.

Definition 7.15 Positive semidefinite matrix (pozitivno semidefinitna matrika)

A square matrix \(\mat K\) of order \(n\) is positive semidefinite if it is symmetric (definition 1.102) and for every column \(\vek d\) with \(n\) entries

\[\vek d^\T \mat K\,\vek d = \sum_{\mathrm{i}=1}^n \sum_{\mathrm{j}=1}^n d_{\mathrm{i}}\,K_{\mathrm{ij}}\,d_{\mathrm{j}} \ge 0 .\]

Source: KREYSZIG §8.4, problem 24 (PDF p. 372): positive semidefiniteness of a quadratic form and of its symmetric matrix.

The matrix \(\frac{EA}{h}\left[\begin{smallmatrix} 1 & -1 & 0 \\ -1 & 2 & -1 \\ 0 & -1 & 1 \end{smallmatrix}\right]\) of equation (7.13) is symmetric and its quadratic form is \(\vek d^\T\mat K\,\vek d = \frac{EA}{h}\big((d_1 - d_0)^2 + (d_2 - d_1)^2\big)\). We check this by expanding, \(d_0 (d_0 - d_1) + d_1 (-d_0 + 2d_1 - d_2) + d_2 (-d_1 + d_2) = d_0^2 - 2 d_0 d_1 + 2 d_1^2 - 2 d_1 d_2 + d_2^2\). Both squares are nonnegative, so the form is nonnegative and the matrix is positive semidefinite, and zero occurs at \(\vek d = (1, 1, 1)\), so it is not positive definite. We notice that \(\mat K\,\vek d\) is also zero there. Is this a coincidence? No, for a semidefinite matrix this is always true.

Semidefiniteness is not a property of every symmetric matrix. The matrix \(\mat K' = \frac{EA}{h}\left[\begin{smallmatrix} 1 & -1{,}1 \\ -1{,}1 & 1 \end{smallmatrix}\right]\) differs from the bar element matrix only in the off-diagonal entry (\(-1{,}1\) instead of \(-1\)) and it is symmetric. The condition "for every \(\vek d\)" fails already for one column: for \(\vek d = (1, 1)\) we have \(\vek d^\T\mat K'\vek d = \frac{EA}{h}(1 - 2{,}2 + 1) = -0{,}2\,\frac{EA}{h} < 0\). The eigenvalues are \(-0{,}1\,\frac{EA}{h}\) and \(2{,}1\,\frac{EA}{h}\). Physically, an equal displacement of both nodes would release energy, which an elastic body cannot do. With \(-1\) instead of \(-1{,}1\) the same computation gives \(1 - 2 + 1 = 0\), which the condition still accepts.

Lemma 7.16 Zero energy means zero force (ničelna energija pomeni ničelno silo)

Let \(\mat K\) be a positive semidefinite matrix of order \(n\) and \(\vek d\) a column with \(n\) entries. Then \(\mat K\,\vek d = \vek 0\) if and only if \(\vek d^\T\mat K\,\vek d = 0\).

Proof

The direction from left to right is immediate. For the converse we choose an arbitrary column \(\vek y\) and a number \(t\) and estimate the energy of the column \(\vek d + t\,\vek y\).

  1. If \(\mat K\,\vek d = \vek 0\), then \(\vek d^\T\mat K\,\vek d = \vek d^\T\vek 0 = 0\).
  2. Let \(\vek d^\T\mat K\,\vek d = 0\), \(\vek y\) an arbitrary column with \(n\) entries and \(t\) an arbitrary number. By lemma 1.101 and the symmetry of \(\mat K\) we have \(\vek y^\T\mat K\,\vek d = (\mat K\,\vek y)^\T\vek d = \vek d^\T\mat K\,\vek y\), since this is a number and equals its transpose. Hence \(g(t) = (\vek d + t\,\vek y)^\T\mat K\,(\vek d + t\,\vek y) = \vek d^\T\mat K\,\vek d + 2t\,\vek y^\T\mat K\,\vek d + t^2\,\vek y^\T\mat K\,\vek y\), and since \(\vek d^\T\mat K\,\vek d = 0\), \(g(t) = 2t\,\vek y^\T\mat K\,\vek d + t^2\,\vek y^\T\mat K\,\vek y\).
  3. By definition 7.15, \(g(t) \ge 0\) for every \(t\), and \(g(0) = 0\). The function \(g\) is a polynomial, hence differentiable, and on the interval \((-1, 1)\) it attains its smallest value \(0\) at the interior point \(t = 0\). By lemma 1.82, \(g'(0) = 0\).
  4. The derivative is \(g'(t) = 2\,\vek y^\T\mat K\,\vek d + 2t\,\vek y^\T\mat K\,\vek y\), so \(g'(0) = 2\,\vek y^\T\mat K\,\vek d = 0\), which holds for every \(\vek y\).
  5. For \(\vek y = \vek e_{\mathrm{i}}\), the \(i\)-th column of the identity matrix, \(\vek e_{\mathrm{i}}^\T\mat K\,\vek d\) is the \(i\)-th entry of the column \(\mat K\,\vek d\) (definition 1.98). Hence every entry of the column \(\mat K\,\vek d\) is zero, so \(\mat K\,\vek d = \vek 0\).

Source: The proof is not from a source.

Both assumptions of the lemma, symmetry and semidefiniteness, are needed, and each one breaks a different step of the proof. Without symmetry take \(\mat K = \left[\begin{smallmatrix} 0 & 1 \\ -1 & 0 \end{smallmatrix}\right]\): for every \(\vek d\) we have \(\vek d^\T\mat K\,\vek d = d_1 d_2 - d_2 d_1 = 0\), but for \(\vek d = (1, 0)\) we have \(\mat K\,\vek d = (0, -1) \ne \vek 0\). Step 2 fails: for \(\vek y = (0, 1)\) we have \(\vek y^\T\mat K\,\vek d = K_{21} = -1\) and \(\vek d^\T\mat K\,\vek y = K_{12} = 1\), so the equality does not hold. Without semidefiniteness take the symmetric \(\mat K = \mathrm{diag}(1, -1)\): for \(\vek d = (1, 1)\) the energy is \(1 - 1 = 0\), but \(\mat K\,\vek d = (1, -1) \ne \vek 0\). Step 3 fails: for \(\vek y = \vek e_1\) we have \(g(t) = (1 + t)^2 - 1 = 2t + t^2\), which at \(t = -1\) equals \(-1 < 0\), so \(g\) has no smallest value at \(t = 0\) and \(g'(0) = 2 \ne 0\).

The proof showed that for a positive semidefinite matrix there is no difference between the two questions of whether a column \(\vek d\) requires a force and whether it has energy. If the energy is zero, every entry of the force column \(\mat K\,\vek d\) is zero too. For a structure we read this physically: a displacement in which nothing deforms needs no forces. COOK says this for a rigid displacement (»If {D} represents a small rigid-body displacement, then [K]{D} = {0}«), and no load is needed (COOK, PDF p. 52). What remains is the question of which displacements of a bar have zero energy. There is exactly one answer.

Lemma 7.17 Displacements of a bar with zero energy (premiki palice z ničelno energijo)

A bar has nodes \(0, 1, \dots, n\) in order along the axis \(x\) and elements \(1, \dots, n\), where element \(e\) has the nodes \(e - 1\) and \(e\), length \(h_{\mathrm{e}} > 0\) and axial stiffness \(EA_{\mathrm{e}} > 0\). Let \(\mat K\) be the structure matrix of theorem 7.13. Then

\[\vek d^\T\mat K\,\vek d = \sum_{\mathrm{e}=1}^{n} \frac{EA_{\mathrm{e}}}{h_{\mathrm{e}}}\,(d_{\mathrm{e}} - d_{\mathrm{e}-1})^2 , \tag{7.14}\]

the matrix \(\mat K\) is positive semidefinite, and \(\mat K\,\vek d = \vek 0\) if and only if \(\vek d = c\,(1, 1, \dots, 1)\) for some number \(c\).

Proof

We must show three things: the form of the energy, semidefiniteness and the kernel. We split the energy by elements, because the matrix is a sum of element contributions.

  1. By item 2 of theorem 7.13, \(\vek d^\T\mat K\,\vek d = \sum_{\mathrm{e}} \vek d_{\mathrm{e}}^\T\,\mat k_{\mathrm{e}}\,\vek d_{\mathrm{e}}\), where \(\vek d_{\mathrm{e}} = \mat Z_{\mathrm{e}}\,\vek d = (d_{\mathrm{e}-1}, d_{\mathrm{e}})\).
  2. By lemma 7.5, \(\mat k_{\mathrm{e}} = \frac{EA_{\mathrm{e}}}{h_{\mathrm{e}}}\left[\begin{smallmatrix} 1 & -1 \\ -1 & 1 \end{smallmatrix}\right]\), so \(\vek d_{\mathrm{e}}^\T\mat k_{\mathrm{e}}\,\vek d_{\mathrm{e}} = \frac{EA_{\mathrm{e}}}{h_{\mathrm{e}}}\,(d_{\mathrm{e}-1}^2 - 2 d_{\mathrm{e}-1} d_{\mathrm{e}} + d_{\mathrm{e}}^2) = \frac{EA_{\mathrm{e}}}{h_{\mathrm{e}}}\,(d_{\mathrm{e}} - d_{\mathrm{e}-1})^2\). Summing over \(e\) gives equation (7.14).
  3. Every term of the sum is nonnegative, because \(EA_{\mathrm{e}}\) and \(h_{\mathrm{e}}\) are positive, so \(\vek d^\T\mat K\,\vek d \ge 0\). The matrix \(\mat K\) is symmetric (corollary 7.14), hence positive semidefinite (definition 7.15).
  4. By lemma 7.16, \(\mat K\,\vek d = \vek 0\) if and only if \(\vek d^\T\mat K\,\vek d = 0\). A sum of nonnegative terms is zero if and only if every term is zero, so \(d_{\mathrm{e}} = d_{\mathrm{e}-1}\) for every \(e = 1, \dots, n\).
  5. From \(d_0 = d_1 = \dots = d_{\mathrm{n}}\) it follows that \(\vek d = c\,(1, \dots, 1)\) with \(c = d_0\). Conversely, for such \(\vek d\) every term of the sum is zero.

Source: The proof is not from a source.

For the example of equation (7.13), \(n = 2\), \(EA_{\mathrm{e}}/h_{\mathrm{e}} = 3{,}079 \cdot 10^6\) N/m and \(\vek d^\T\mat K\,\vek d = 3{,}079 \cdot 10^6\,\big((d_1 - d_0)^2 + (d_2 - d_1)^2\big)\) N/m, as we expanded it before. The displacement of the bar as a whole is the only one that requires no force. For trusses in the plane and in space we will see that other displacements can also have zero energy. A displacement of the whole truss as a body and a rotation of the truss about a point stretch no bar (section 7.5), and this is exactly what the supports will have to prevent.

7.3.2 Supports and the reduced system (podpore in reducirani sistem)

The matrix \(\mat K\) of theorem 7.13 lacks a support. The weak form of chapter 6 says what to do with it. At a node where a support prescribes the displacement, the test functions are zero (definition 6.6), so we get no equation from there. Equations come only from test functions that are zero at all supported nodes, that is from the hat functions of the free nodes. We therefore divide the unknowns into two parts. A free unknown is the displacement of a node that no support prescribes, and a prescribed unknown is one whose value is given, for the hanging bar \(d_0 = 0\). We denote the free ones by the index \(\mathrm{f}\) and the prescribed ones by the index \(\mathrm{p}\). We renumber the unknowns so that the free ones come before the prescribed ones, and rearrange the rows and columns of the matrix in the same way. This is only a renaming of unknowns, which changes no equation and no value of \(\vek d^\T\mat K\,\vek d\), and the symmetry remains. The matrix, the columns of unknowns and the right-hand sides split into blocks:

\[\mat K = \begin{pmatrix} \mat K_{\mathrm{ff}} & \mat K_{\mathrm{fp}} \\ \mat K_{\mathrm{pf}} & \mat K_{\mathrm{pp}} \end{pmatrix} , \qquad \vek d = \begin{pmatrix} \vek d_{\mathrm{f}} \\ \vek d_{\mathrm{p}} \end{pmatrix} , \qquad \vek f = \begin{pmatrix} \vek f_{\mathrm{f}} \\ \vek f_{\mathrm{p}} \end{pmatrix} . \tag{7.15}\]

The block \(\mat K_{\mathrm{ff}}\) has the rows and columns of the free unknowns, and the block \(\mat K_{\mathrm{fp}}\) the rows of the free and the columns of the prescribed ones. For the hanging bar, \(\mat K_{\mathrm{ff}}\) is the matrix that remains when we strike out row and column \(0\) (figure 7.7).

When does the block \(\mat K_{\mathrm{ff}}\) have an inverse, that is, when are the supports sufficient? The answer is a theorem. It requires the supports to stop all displacements that the structure does not resist with any force.

Theorem 7.18 Reduced system (reducirani sistem)

Let \(\mat K\) and \(\vek f\) be the matrix and the right-hand side of a structure of theorem 7.13 with element matrices that satisfy the hypothesis of corollary 7.14, let the unknowns be divided into free and prescribed as in equation (7.15), and let the values \(\vek d_{\mathrm{p}}\) be given. Let the column \(\vek d\) with the given \(\vek d_{\mathrm{p}}\) satisfy \((\mat K\,\vek d)_{\mathrm{i}} = f_{\mathrm{i}}\) for every free unknown \(i\). Then \(\vek d_{\mathrm{f}}\) is a solution of the system

\[\mat K_{\mathrm{ff}}\,\vek d_{\mathrm{f}} = \vek f_{\mathrm{f}} - \mat K_{\mathrm{fp}}\,\vek d_{\mathrm{p}} . \tag{7.16}\]

For the bar of item 3 of theorem 7.13 the condition is satisfied by the displacements of the finite element solution, the field \(u_{\mathrm{h}} = \sum_{\mathrm{j}} d_{\mathrm{j}}\,\psi_{\mathrm{j}}\) with the given \(\vek d_{\mathrm{p}}\) and \(B(u_{\mathrm{h}}, \psi_{\mathrm{i}}) = \ell(\psi_{\mathrm{i}})\) for every free unknown \(i\). If there is no nonzero \(\vek d\) with \(\vek d_{\mathrm{p}} = \vek 0\) and \(\vek d^\T\mat K\,\vek d = 0\), then \(\mat K_{\mathrm{ff}}\) is positive definite, the system (7.16) has exactly one solution, and Gaussian elimination without row exchanges reaches it with all pivots positive.

Proof

We must show that the rows of the free unknowns give the system (7.16), that for the bar the finite element solution satisfies them, and that the hypothesis guarantees positive definiteness. The latter is then covered by theorem 6.29.

  1. The bar. The test function \(\psi_{\mathrm{i}}\) of a free node is zero at all prescribed nodes, so by definition 6.6 it is a test function. The equation \(B(u_{\mathrm{h}}, \psi_{\mathrm{i}}) = \ell(\psi_{\mathrm{i}})\) is thus the equation that the weak form requires for every free unknown \(i\).
  2. We insert the field \(u_{\mathrm{h}} = \sum_{\mathrm{j}} d_{\mathrm{j}}\,\psi_{\mathrm{j}}\) into the first argument. The form \(B\) is linear in the first argument (definition 6.4), so \(B(u_{\mathrm{h}}, \psi_{\mathrm{i}}) = \sum_{\mathrm{j}} B(\psi_{\mathrm{j}}, \psi_{\mathrm{i}})\,d_{\mathrm{j}} = \sum_{\mathrm{j}} K_{\mathrm{ij}}\,d_{\mathrm{j}}\), where \(K_{\mathrm{ij}} = B(\psi_{\mathrm{j}}, \psi_{\mathrm{i}})\) by theorem 7.13. The same theorem gives \(\ell(\psi_{\mathrm{i}}) = f_{\mathrm{i}}\). For the bar every row \(i\) of a free node is therefore \(\sum_{\mathrm{j}} K_{\mathrm{ij}}\,d_{\mathrm{j}} = f_{\mathrm{i}}\), which is the hypothesis of the theorem.
  3. By hypothesis \(\sum_{\mathrm{j}} K_{\mathrm{ij}}\,d_{\mathrm{j}} = f_{\mathrm{i}}\) for every free unknown \(i\). We split the sum over \(j\) into free and prescribed unknowns. By the rule for the product of matrices (definition 1.98, applied to blocks), the rows of the free unknowns are \(\mat K_{\mathrm{ff}}\,\vek d_{\mathrm{f}} + \mat K_{\mathrm{fp}}\,\vek d_{\mathrm{p}} = \vek f_{\mathrm{f}}\). We move the term with the prescribed values to the right and obtain equation (7.16).
  4. The block \(\mat K_{\mathrm{ff}}\) is symmetric because it is part of the symmetric matrix \(\mat K\) (corollary 7.14), \(K_{\mathrm{ij}} = K_{\mathrm{ji}}\) also for free \(i, j\).
  5. Let \(\vek y \ne \vek 0\) be a column of free unknowns and \(\vek z = (\vek y, \vek 0)\) the column of all unknowns, which is nonzero and has \(\vek z_{\mathrm{p}} = \vek 0\). By the rule for the product of matrices on blocks, \(\vek z^\T\mat K\,\vek z = \vek y^\T\mat K_{\mathrm{ff}}\,\vek y\), since the other three blocks multiply the zero column.
  6. By corollary 7.14, \(\vek z^\T\mat K\,\vek z \ge 0\), and by the hypothesis it is not zero, so \(\vek y^\T\mat K_{\mathrm{ff}}\,\vek y > 0\). The block \(\mat K_{\mathrm{ff}}\) is therefore a positive definite matrix (definition 6.27), and the claim about the solution and the pivots is theorem 6.29.

Source: COOK (2.7-1) to (2.7-3), PDF p. 54, and (2.7-5) to (2.7-8), PDF pp. 55-56, FELIPPA (3.21) to (3.23), PDF p. 45 (»striking out« of rows and columns), ONATE1 (2.85), (2.86), PDF p. 98, EP (8.2.41), p. 542 (first row and first column omitted, a system with a known right-hand column remains). The proof in steps is not from the sources.

The proof showed that the reduced system is not a new procedure but the rows of the weak form that we had in chapter 6 for the free hat functions, and that the positive definiteness of the block follows from the condition on the supports. The condition in words: the supports must stop every displacement in which the energy would stay zero. For a bar this condition is simple.

Corollary 7.19 A supported bar (podprta palica)

Let the bar be as in lemma 7.17 and let at least one unknown be prescribed, \(d_{\mathrm{k}} = \bar d_{\mathrm{k}}\) for some \(k\). Then \(\mat K_{\mathrm{ff}}\) is positive definite, the system (7.16) has exactly one solution, and elimination reaches it with positive pivots.

Proof

We must show that the hypothesis of theorem 7.18 holds.

  1. Let \(\vek d \ne \vek 0\) with \(\vek d_{\mathrm{p}} = \vek 0\) and \(\vek d^\T\mat K\,\vek d = 0\). By lemma 7.16, \(\mat K\,\vek d = \vek 0\), so by lemma 7.17 \(\vek d = c\,(1, \dots, 1)\).
  2. The unknown \(d_{\mathrm{k}}\) is prescribed, so \(d_{\mathrm{k}} = 0\) in \(\vek d_{\mathrm{p}} = \vek 0\). From \(d_{\mathrm{k}} = c\) it follows that \(c = 0\) and \(\vek d = \vek 0\), a contradiction.
  3. The hypothesis of theorem 7.18 therefore holds, and the claim is the theorem itself.

Source: The proof is not from a source.

For a bar the supports therefore cannot be chosen wrongly: any node with a given displacement suffices. For trusses the condition will be stricter and we will have to check it.

We test it on the hanging bar of two elements. The free unknowns are \(d_1\) and \(d_2\), the prescribed one is \(d_0 = 0\). The block \(\mat K_{\mathrm{ff}}\) is the matrix that remains when we strike out row and column \(0\) of the matrix of equation (7.13), \(\mat K_{\mathrm{fp}}\) is the column \(\frac{EA}{h}(-1, 0)\), and because of \(d_0 = 0\) we have \(\mat K_{\mathrm{fp}}\,\vek d_{\mathrm{p}} = \vek 0\). The system (7.16) is

\[\frac{EA}{h} \begin{pmatrix} 2 & -1 \\ -1 & 1 \end{pmatrix} \begin{pmatrix} d_1 \\ d_2 \end{pmatrix} = \begin{pmatrix} 30{,}05 \\ 15{,}02 \end{pmatrix}\ \text{N} . \tag{7.17}\]

Elimination starts with the pivot \(2EA/h = 6{,}158 \cdot 10^6\) N/m. We add half of the first row to the second and obtain \(\big(1 - \tfrac12\big)\frac{EA}{h}\,d_2 = 15{,}02 + \tfrac12\,30{,}05\) N. The second pivot is \(\frac{EA}{2h} = 1{,}539 \cdot 10^6\) N/m, positive, as corollary 7.19 predicts, and the right-hand side is \(30{,}05\) N. From this \(d_2 = 30{,}05\ \text{N} / (1{,}539 \cdot 10^6\ \text{N/m}) = 19{,}52\) µm. The first row gives \(d_1 = \big(30{,}05\ \text{N} + \frac{EA}{h}\,d_2\big) / (2EA/h) = 14{,}64\) µm. Both displacements are the same as in chapter 6 and are exact (theorem 6.38).

What happens if there is no support? Elimination of the whole matrix of equation (7.13) starts with the pivot \(\frac{EA}{h}\). After the first step \(\frac{EA}{h}\left[\begin{smallmatrix} 1 & -1 \\ -1 & 1 \end{smallmatrix}\right]\) remains, the second pivot is again \(\frac{EA}{h}\), and after the second step the third entry is \(\frac{EA}{h}(1 - 1) = 0\). The third pivot is zero, we cannot divide, and elimination fails. The positive pivots of theorem 6.29 are lost exactly where the energy is zero.

7.3.3 A prescribed displacement that is not zero (predpisan pomik, ki ni nič)

A support often does not only hold a node but moves it. The foundation of a building can settle, or a structure can be deliberately clamped into a displaced support. Does theorem 7.18 cover this? It does, because it does not require \(\vek d_{\mathrm{p}} = \vek 0\). Take the bar of chapter 6 fixed at both ends (subsection 6.4.2), where the lower support has settled by \(\bar u = 0{,}1\) mm downward. The bar has the same data as before and two elements, nodes \(0\), \(1\), \(2\). The prescribed ones are \(d_0 = 0\) and \(d_2 = \bar u\), only \(d_1\) is free. The matrix \(\mat K_{\mathrm{ff}}\) is a single entry, \(K_{11} = 2EA/h = 6{,}158 \cdot 10^6\) N/m, and the row \(\mat K_{\mathrm{fp}}\) is \(\big(K_{10}, K_{12}\big) = \frac{EA}{h}(-1, -1)\). The term with the prescribed values is \(\mat K_{\mathrm{fp}}\,\vek d_{\mathrm{p}} = -\frac{EA}{h}\,\bar u\), and equation (7.16) is

\[\frac{2EA}{h}\,d_1 = f_1 + \frac{EA}{h}\,\bar u = 30{,}05\ \text{N} + 307{,}88\ \text{N} = 337{,}93\ \text{N} , \tag{7.18}\]

where \(EA\,\bar u/h = 3{,}079 \cdot 10^6\ \text{N/m} \cdot 10^{-4}\ \text{m} = 307{,}88\) N. From this \(d_1 = 54{,}88\) µm.

We check against the known solution. The true field of this problem is \(a\,x\,(L - x) + \bar u\,x/L\) (subsection 6.4.2), at the middle \(x = 5\) m it is \(a \cdot 25\ \text{m}^2 + \bar u/2 = 4{,}88\ \text{µm} + 50{,}00\ \text{µm} = 54{,}88\) µm, the same number. Equation (7.18) gives it in two parts: \(30{,}05\ \text{N}/(6{,}158 \cdot 10^6\ \text{N/m}) = 4{,}88\) µm from the weight and \(307{,}88\ \text{N}/(6{,}158 \cdot 10^6\ \text{N/m}) = 50{,}00\) µm from the settlement, that is half of the settlement, because node \(1\) is in the middle between the supports.

Why did \(307{,}88\) N appear on the right-hand side? Imagine that we clamp the second element at its lower end into the displaced support and hold node \(1\) at \(d_1 = 0\). The element stretches by \(\bar u\) and pulls node \(1\) downward with the force \(EA\,\bar u/h\). When solving for the free node we must subtract this force, so on the right-hand side we add it as a load (figure 7.8). The prescribed displacement acts on the free node as a load equal to the force that would be needed to stretch the element by this displacement while the free node is held.

In a computer program, splitting the matrix into blocks is laborious, because the rows and columns would have to be rearranged. A procedure that keeps the size of the system is therefore often used (COOK, PDF pp. 54-55, »without ... changing its size, or rearranging its terms«). For every prescribed unknown \(d_{\mathrm{k}} = \bar d_{\mathrm{k}}\) we do three things: from the right-hand side of every other row \(i\) we subtract \(K_{\mathrm{ik}}\,\bar d_{\mathrm{k}}\), we replace the row and column \(k\) of the matrix by zeros and put \(1\) on the diagonal, and on the right-hand side of row \(k\) we put \(\bar d_{\mathrm{k}}\). Let us prove that the solution is the same.

Row \(k\) of the new matrix is \((0, \dots, 1, \dots, 0)\) and the right-hand side is \(\bar d_{\mathrm{k}}\), so the equation says \(d_{\mathrm{k}} = \bar d_{\mathrm{k}}\), which is exactly the prescribed value. Row \(i\) of a free node has a zero in column \(k\), so it no longer contains the unknown \(d_{\mathrm{k}}\), and on the right-hand side it has \(f_{\mathrm{i}} - K_{\mathrm{ik}}\,\bar d_{\mathrm{k}}\). This is row \(i\) of the system (7.16), in which the term \(K_{\mathrm{ik}}\,\bar d_{\mathrm{k}}\) has been moved to the right. Only the rows \(d_{\mathrm{k}} = \bar d_{\mathrm{k}}\), which do not mix unknowns, have been added to the free rows, so the solution for the free unknowns is the same as for equation (7.16). For the settled bar of equation (7.18) the nodes \(0\) and \(2\) are prescribed. The new matrix is diagonal,

\[\begin{pmatrix} 1 & 0 & 0 \\ 0 & 2EA/h & 0 \\ 0 & 0 & 1 \end{pmatrix} \begin{pmatrix} d_0 \\ d_1 \\ d_2 \end{pmatrix} = \begin{pmatrix} 0 \\ 337{,}93\ \text{N} \\ \bar u \end{pmatrix} , \tag{7.19}\]

and from it we read \(d_0 = 0\), \(d_1 = 337{,}93\ \text{N}/(2EA/h) = 54{,}88\) µm, \(d_2 = \bar u\). The matrix is still symmetric, which preserves the advantage of symmetric storage. The ones on the diagonal have a different unit than \(2EA/h\) in N/m, which is unpleasant for large structures. COOK mentions as an alternative that the original \(K_{\mathrm{kk}}\) stays on the diagonal and \(K_{\mathrm{kk}}\,\bar d_{\mathrm{k}}\) goes to the right-hand side of row \(k\) (COOK, PDF p. 55). The solution is again the same, because row \(k\) again says \(d_{\mathrm{k}} = \bar d_{\mathrm{k}}\), only with both sides multiplied by \(K_{\mathrm{kk}}\).

Prescribed values can also be imposed in two other ways, with a penalty (penalty method) and with Lagrange multipliers. COOK only mentions them: »Boundary conditions can also be treated by Lagrange multipliers and by the penalty method« (COOK, PDF p. 56). We will meet the penalty in frames in chapter 12, and the multipliers in chapter 8, where they appear as constraint forces. In this chapter we stay with the division into blocks and with the procedure that keeps the size.

7.3.4 Reactions (reakcije)

The reduced system does not use the rows of the prescribed unknowns. We must not throw these rows away, because they hold the forces with which the supports hold the structure. A reaction is the force that a support exerts on the structure at the node of a prescribed unknown, in the direction of that unknown. How do we obtain it?

Row \(i\) of the product \(\mat K\,\vek d\) is the force that we must give to node \(i\) from outside to maintain the displacements \(\vek d\). Column \(j\) of the matrix \(\mat K\) is namely the force at the nodes that is needed for a unit displacement of unknown \(j\) with the other unknowns zero (definition 7.4), and row \(i\) of the product is the sum of these contributions at the given \(d_{\mathrm{j}}\). At a free node this force is provided by the load, and \((\mat K\,\vek d)_{\mathrm{i}} = f_{\mathrm{i}}\) is exactly an equation of the system. At a prescribed node the load \(f_{\mathrm{i}}\) carries a part, and the remainder must be provided by the support. The reaction is therefore the difference

\[r_{\mathrm{i}} = (\mat K\,\vek d)_{\mathrm{i}} - f_{\mathrm{i}} , \qquad i \text{ prescribed} ,\]

which for the blocks of equation (7.15) means

\[\vek r_{\mathrm{p}} = \mat K_{\mathrm{pf}}\,\vek d_{\mathrm{f}} + \mat K_{\mathrm{pp}}\,\vek d_{\mathrm{p}} - \vek f_{\mathrm{p}} . \tag{7.20}\]

At free unknowns there is no support, \(r_{\mathrm{i}} = 0\), and all the conditions together are written as \(\mat K\,\vek d = \vek f + \vek r\) with a column \(\vek r\) that is nonzero only at the prescribed unknowns. The reactions are computed afterwards and do not influence the solution for the displacements, since the free system of equation (7.16) does not contain the prescribed rows. ONATE1 says in words that the reactions are computed »a posteriori« from the already known displacements (ONATE1 (2.26), PDF p. 74, and (2.85), PDF p. 98), EP with the row that remains unused when the first row and column are omitted and from which we get the unknown reaction (EP (8.2.41) and (8.2.45), pp. 542-543), FELIPPA multiplies the whole solution by the matrix and obtains the reactions besides the known loads (FELIPPA (3.26), PDF p. 46), COOK obtains them by multiplying the solution by the rows of the matrix that were discarded when the supports were entered (COOK, PDF p. 56).

The hanging bar of two elements. Only \(d_0 = 0\) is prescribed, row \(0\) of the matrix of equation (7.13) is \(\frac{EA}{h}(1, -1, 0)\), and \((\mat K\,\vek d)_0 = \frac{EA}{h}\,(d_0 - d_1) = -3{,}079 \cdot 10^6\ \text{N/m} \cdot 14{,}64\ \text{µm} = -45{,}07\) N. The load of the node is \(f_0 = 15{,}02\) N, so

\[r_0 = -45{,}073\ \text{N} - 15{,}024\ \text{N} = -60{,}097\ \text{N} .\]

The support pulls the bar upward (the axis points down) with the force \(60{,}097\) N, which is the weight of the whole bar \(qL = 6{,}0097 \cdot 10 = 60{,}097\) N. The settled bar has two reactions. Rows \(0\) and \(2\) of the matrix are \(\frac{EA}{h}(1, -1, 0)\) and \(\frac{EA}{h}(0, -1, 1)\), and with \(d = (0,\ 54{,}88\ \text{µm},\ 100{,}00\ \text{µm})\) we get \((\mat K\,\vek d)_0 = -3{,}0788 \cdot 10^6 \cdot 54{,}88 \cdot 10^{-6} = -168{,}96\) N and \((\mat K\,\vek d)_2 = 3{,}0788 \cdot 10^6 \cdot (100{,}00 - 54{,}88) \cdot 10^{-6} = 138{,}92\) N. After subtracting the loads \(f_0 = f_2 = 15{,}02\) N, computed with unrounded values,

\[r_0 = -183{,}99\ \text{N} , \qquad r_2 = 123{,}89\ \text{N} .\]

The upper support pulls upward with \(183{,}99\) N, and the lower one pulls downward with \(123{,}89\) N, because the settlement stretches the bar at its lower end. The sum of the reactions is \(-60{,}10\) N, again the weight of the bar. Is this a coincidence?

Lemma 7.20 Balance of reactions and loads (ravnovesje reakcij in bremen)

Let \(\vek d\) be a solution of the reduced system of a bar from theorem 7.18 and \(\vek r = \mat K\,\vek d - \vek f\) the column of reactions, which is zero at free unknowns. Then

\[\sum_{\mathrm{i}} r_{\mathrm{i}} + \sum_{\mathrm{i}} f_{\mathrm{i}} = 0 , \tag{7.21}\]

the sum over all nodes: the reactions are equal in magnitude and opposite in sign to the sum of all nodal loads.

Proof

We must show that the column of ones \(\vek 1 = (1, \dots, 1)\) is multiplied by \(\mat K\) into zero, and that this gives the claim when the equation \(\mat K\,\vek d = \vek f + \vek r\) is multiplied from the left.

  1. By lemma 7.6, \(\mat k_{\mathrm{e}}\,(1, 1) = \vek 0\) for every element. The selection matrix picks from \(\vek 1\) the two components that belong to element \(e\), these are ones, \(\mat Z_{\mathrm{e}}\,\vek 1 = (1, 1)\), so by theorem 7.13 \(\mat K\,\vek 1 = \sum_{\mathrm{e}} \mat Z_{\mathrm{e}}^\T\,\mat k_{\mathrm{e}}\,(1, 1) = \vek 0\).
  2. For free unknowns the row is an equation of (7.16), and for prescribed ones it is the definition of the column \(\vek r\). Together \(\mat K\,\vek d = \vek f + \vek r\) holds.
  3. We multiply the equation from the left by the row \(\vek 1^\T\): \(\vek 1^\T\mat K\,\vek d = \vek 1^\T\vek f + \vek 1^\T\vek r\).
  4. The matrix \(\mat K\) is symmetric (corollary 7.14), so by lemma 1.101 \(\vek 1^\T\mat K = (\mat K^\T\vek 1)^\T = (\mat K\,\vek 1)^\T = \vek 0^\T\) by step 1. The left-hand side is zero, and the right-hand side is \(\vek 1^\T\vek f + \vek 1^\T\vek r = \sum_{\mathrm{i}} f_{\mathrm{i}} + \sum_{\mathrm{i}} r_{\mathrm{i}}\), which is equation (7.21).

Source: The proof is not from a source in this form. FELIPPA, PDF p. 46: »It is easy to check that the complete force system is in equilibrium«.

The proof showed that the reactions and the loads are in balance because a rigid displacement of the bar needs no force, that is because of the same zero energy that cost the matrix \(\mat K\) its inverse. We check on the examples: hanging bar \(15{,}024 + 30{,}049 + 15{,}024 - 60{,}097 = 0\), settled bar \(15{,}024 + 30{,}049 + 15{,}024 - 183{,}989 + 123{,}892 = 0\) (node \(1\) is not supported and has \(r_1 = 0\)). So checking the reactions is the first thing we do after a computation: the sum of the reactions must be opposite to the sum of the loads. The check is necessary but not sufficient. The reactions would satisfy equation (7.21) even with a wrongly computed stiffness, as we will see for the bridge in section 7.7.

For the hanging bar the lemma itself says that the only reaction is \(r_0 = -\sum_{\mathrm{i}} f_{\mathrm{i}} = -qL\), because this is the only supported unknown. The sum of the nodal loads is the whole load, because on every element the two shape functions add up to \(1\) (lemma 7.3), so \(\sum_{\mathrm{i}} f_{\mathrm{i}} = \ell\big(\sum_{\mathrm{i}} \psi_{\mathrm{i}}\big) = \int_0^L q\,\mathrm{d}x = qL\). Therefore the reaction is exact for every number of elements. The computation for \(n = 1\), \(2\), \(4\) elements (SymPy and NumPy) always gives \(-60{,}097\) N. For the settled bar two unknowns are supported, the lemma gives only the sum, and each reaction separately should be exact too. Why?

Let us also look at the force in an element. By section 7.1.4, \(N_{\mathrm{e}} = EA\,(d_{\mathrm{e}} - d_{\mathrm{e}-1})/h\) is constant on the element. For the bar of two elements \(N_1 = 3{,}079 \cdot 10^6 \cdot 14{,}64 \cdot 10^{-6} = 45{,}07\) N and \(N_2 = 3{,}079 \cdot 10^6 \cdot (19{,}52 - 14{,}64) \cdot 10^{-6} = 15{,}02\) N. The true axial force is \(N(x) = q\,(L - x)\), at the support \(N(0) = qL = 60{,}10\) N. The force in the first element is \(45{,}07\) N, so \(qh/2 = 15{,}02\) N too little, exactly as much as \(f_0\). For four elements the forces are \(52{,}585\), \(37{,}561\), \(22{,}536\) and \(7{,}512\) N, each is the average of the true force \(q\,(L - x)\) on its element. The first average is \(q\,(L - h/2)\), so \(N_1 = N(0) - qh/2\). Therefore from the equation \(r_0 = (\mat K\,\vek d)_0 - f_0 = -N_1 - f_0\) it follows that

\[r_0 = -\big(N_1 + f_0\big) = -\big(N(0) - qh/2 + qh/2\big) = -N(0) . \tag{7.22}\]

The support carries the force of the first element and that part of the weight that hangs on node \(0\). The force in the element at the support is inexact by \(qh/2\), and the reaction is exact, because the missing part is added to it by the load of the node. This holds more generally.

The reaction is exact if the displacements of both nodes of the first element are exact. For the hanging bar this is guaranteed by theorem 6.38. For a bar fixed at both ends that theorem says nothing, because it is written for a single support at \(x = 0\), so we prove the exactness of the nodes separately. The proof follows the same idea: the error is orthogonal to the hat functions of the free nodes, and from this it follows that the error at all nodes is zero.

Lemma 7.21 Exact nodal displacements of a bar fixed at both ends (točni pomiki vozlišč palice, pritrjene na obeh koncih)

A bar has nodes \(0, 1, \dots, n\) at \(0 = x_0 < x_1 < \dots < x_{\mathrm{n}} = L\) and elements \([x_{\mathrm{e}-1}, x_{\mathrm{e}}]\) with length \(h_{\mathrm{e}} = x_{\mathrm{e}} - x_{\mathrm{e}-1}\) and axial stiffness \(EA_{\mathrm{e}} > 0\), which is constant on each element (so there is a node wherever \(EA\) changes). The load \(q\) is continuous on each element. The displacements \(d_0\) and \(d_{\mathrm{n}}\) are prescribed. Let \(u\) be a piecewise continuously differentiable solution of the weak form with \(u(0) = d_0\) and \(u(L) = d_{\mathrm{n}}\), and \(u_{\mathrm{h}} = \sum_{\mathrm{j}} d_{\mathrm{j}}\,\psi_{\mathrm{j}}\) the finite element solution of theorem 7.18, where the free unknowns are \(d_1, \dots, d_{\mathrm{n}-1}\). Then \(d_{\mathrm{j}} = u(x_{\mathrm{j}})\) for every \(j = 0, 1, \dots, n\).

Proof

We must show that the error \(e = u - u_{\mathrm{h}}\) is zero at all nodes. The hat function of every free node is orthogonal to the error, which gives equal forces in neighbouring elements, and the two ends close them.

  1. The function \(e\) is continuous and piecewise continuously differentiable on the same partition as \(u\) and \(u_{\mathrm{h}}\). Since \(\psi_{\mathrm{j}}(x_{\mathrm{i}}) = 1\) for \(j = i\) and \(0\) for \(j \ne i\) (definition 6.25), \(u_{\mathrm{h}}(x_{\mathrm{i}}) = d_{\mathrm{i}}\), so \(e(x_0) = d_0 - u(0) = 0\) and \(e(x_{\mathrm{n}}) = d_{\mathrm{n}} - u(L) = 0\). We write \(e_{\mathrm{j}} = e(x_{\mathrm{j}})\).
  2. For \(k = 1, \dots, n - 1\) the function \(\psi_{\mathrm{k}}\) is zero at \(x_0\) and \(x_{\mathrm{n}}\), so it is a test function (definition 6.6), hence \(B(u, \psi_{\mathrm{k}}) = \ell(\psi_{\mathrm{k}})\). The unknown \(d_{\mathrm{k}}\) is free, so by theorem 7.18 \(B(u_{\mathrm{h}}, \psi_{\mathrm{k}}) = \ell(\psi_{\mathrm{k}})\). By linearity of \(B\) in the first argument, \(B(e, \psi_{\mathrm{k}}) = 0\).
  3. On element \(k\) we have \(\psi_{\mathrm{k}}' = 1/h_{\mathrm{k}}\), on element \(k + 1\) we have \(\psi_{\mathrm{k}}' = -1/h_{\mathrm{k}+1}\), and elsewhere zero (definition 6.25). Since \(EA\) is constant on each element, by lemma 6.12
    \[\begin{aligned} B(e, \psi_{\mathrm{k}}) &= \frac{EA_{\mathrm{k}}}{h_{\mathrm{k}}}\int_{\mathrm{x}_{\mathrm{k}-1}}^{x_{\mathrm{k}}} e'\,\mathrm{d}x - \frac{EA_{\mathrm{k}+1}}{h_{\mathrm{k}+1}}\int_{\mathrm{x}_\mathrm{k}}^{x_{\mathrm{k}+1}} e'\,\mathrm{d}x = s_{\mathrm{k}} - s_{\mathrm{k}+1} , \\ s_{\mathrm{j}} = \frac{EA_{\mathrm{j}}}{h_{\mathrm{j}}}\,(e_{\mathrm{j}} - e_{\mathrm{j}-1}) . \end{aligned}\]
  4. From steps 2 and 3, \(s_1 = s_2 = \dots = s_{\mathrm{n}}\). We denote this number by \(s\).
  5. From the definition of \(s_{\mathrm{j}}\), \(e_{\mathrm{j}} - e_{\mathrm{j}-1} = s\,h_{\mathrm{j}}/EA_{\mathrm{j}}\). The sum over \(j = 1, \dots, n\) gives \(e_{\mathrm{n}} - e_0 = s \sum_{\mathrm{j}} h_{\mathrm{j}}/EA_{\mathrm{j}}\). The left-hand side is zero by step 1, the sum on the right is positive, so \(s = 0\).
  6. From \(s = 0\) it follows that \(e_{\mathrm{j}} = e_{\mathrm{j}-1}\) for every \(j\), so \(e_{\mathrm{j}} = e_0 = 0\) and \(d_{\mathrm{j}} = u_{\mathrm{h}}(x_{\mathrm{j}}) = u(x_{\mathrm{j}})\).

Source: The proof is not from a source. The same reason as in theorem 6.38, which is written for one support.

For \(n = 1\) there are no free unknowns, step 4 says nothing and step 5 gives \(s = 0\) directly. For the settled bar of two elements \(n = 2\) and the lemma says that \(d_1 = 54{,}88\) µm is the exact value, which we checked earlier against the known solution.

Lemma 7.22 Exactness of the reaction of a bar (točnost reakcije palice)

Let the bar have the axis \(x\) from \(0\) to \(L\), loaded only by a piecewise continuous distributed load \(q\), with piecewise continuous axial stiffness \(EA > 0\) that is constant on the first element \([x_0, x_1]\), \(x_0 = 0\), and let it be supported at \(x = 0\) (prescribed displacement). Let \(u\) be the solution of the weak form whose axial force \(N = EA\,u'\) is continuous and piecewise continuously differentiable with \(N' = -q\) (equilibrium of a bar element, chapter 6), \(u_{\mathrm{h}}\) the finite element solution with the same value \(u(0)\), and let \(u_{\mathrm{h}}(x_0) = u(x_0)\) and \(u_{\mathrm{h}}(x_1) = u(x_1)\). Then the reaction at node \(0\) equals the exact reaction,

\[r_0 = -N(0) . \tag{7.23}\]
Proof

We must show that the error \(e = u - u_{\mathrm{h}}\) contributes nothing to the reaction. We write the reaction with the weak form tested with the hat function of the supported node, which is not a test function.

  1. Let \(\varphi = \psi_0\) be the hat function of node \(0\) (definition 6.25). We have \(\varphi(0) = 1\), \(\varphi = 0\) from \(x_1\) onward and \(\varphi' = -1/h_1\) on the first element of length \(h_1 = x_1 - x_0\).
  2. In the finite element method \(r_0 = (\mat K\,\vek d)_0 - f_0\), and row \(0\) is by theorem 7.13 \(\sum_{\mathrm{j}} B(\psi_{\mathrm{j}}, \psi_0)\,d_{\mathrm{j}} - \ell(\psi_0)\). By linearity of \(B\) in the first argument, \(r_0 = B(u_{\mathrm{h}}, \varphi) - \ell(\varphi)\).
  3. For the exact solution \(B(u, \varphi) = \int_0^L N\,\varphi'\,\mathrm{d}x\). By lemma 6.13 with \(N' = -q\) and \(\varphi(L) = 0\) this is \(-N(0)\,\varphi(0) + \int_0^L q\,\varphi\,\mathrm{d}x = -N(0) + \ell(\varphi)\). So \(-N(0) = B(u, \varphi) - \ell(\varphi)\).
  4. We subtract: \(r_0 - (-N(0)) = B(u_{\mathrm{h}}, \varphi) - B(u, \varphi) = -B(e, \varphi)\) by linearity of \(B\) in the first argument.
  5. Since \(\varphi' = 0\) outside the first element and \(EA\) is constant there, \(B(e, \varphi) = \int_0^{x_1} EA\,e'\,\varphi'\,\mathrm{d}x = -\frac{EA}{h_1}\,\big(e(x_1) - e(x_0)\big) = 0\), because \(e(x_0) = 0\) and \(e(x_1) = 0\) by assumption (lemma 6.12). Hence \(r_0 = -N(0)\).

Source: The proof is not from a source.

The proof showed that the reaction stays exact whenever the displacements of both nodes of the first element are exact, no matter how the function differs between them. This is so for the hanging bar (the exactness of the displacements is guaranteed by theorem 6.38) and also for the settled bar (lemma 7.21). There the support is also at \(x = L\) and the same computation with the hat function \(\psi_{\mathrm{n}}\) on the last element, where \(\psi_{\mathrm{n}}' = 1/h_{\mathrm{n}}\), gives in step 3 \(B(u, \psi_{\mathrm{n}}) = N(L) + \ell(\psi_{\mathrm{n}})\) and therefore \(r_2 = N(L)\). The exact force in the bar with the settlement is \(N = EA\,\big(a\,(L - 2x) + \bar u/L\big)\) (subsection 6.4.2), so \(N(0) = 183{,}99\) N and \(N(L) = 123{,}89\) N, and both agree with the reactions \(-183{,}99\) N and \(123{,}89\) N from the computation above. At node \(0\) the reaction thus receives all the accuracy of the displacements, while the force in the element at the support receives only the average.

We now have everything for the computation of a bar with linear elements. We eliminate the supported node (theorem 7.18), move a displacement that is not zero to the right-hand side, solve the system with positive pivots (theorem 6.29), then obtain the reactions from the rows of the supported nodes and check their sum (lemma 7.20). What remains open is what to do when the load varies along the element and straight lines on the element are too coarse. The answer is an element with more nodes, section 7.4.
